# 아이템 경제·가챠·전투 아트 검토 — 2026-10-25

실제 운영 상점 49종, 확정 제작 8종, 합체 유닛 10종의 UI 조회와 지급·소모 코드를 대조했다. 가격표의 정합성과 거래 원자성은 검토할 수 있지만, 실제 이용자 수요·장기 물가·체감 재미를 검증했다고 주장하지 않는다.

## 결론과 수정

- 기본 제작 8종은 v7.508에서 GP 조립비 0·확정 산출로 전환됐다. 재료는 소비하며 무료 아이템 지급이 아니다. 현재 NPC 재료 단가로 비교해도 같은 산출물을 상점에서 직접 사는 것보다 비싸지 않다.
- GP 생성기 교체 전에 정산되지 않은 수입이 유실되던 결함과 만료 직전 1분 미만 잔여 수입 유실을 수정했다. 수익률·기간·가격은 유지하고, 정산·재사용이 한 트랜잭션으로 성공 또는 취소된다.
- 전체 박스 구매 전 총비용/파츠 확률 확인을 추가했다. 취소 또는 계정 변경 시 요청하지 않으며, 확인 후 가격 변경은 서버가 차감 전에 거절한다.
- 합체 파츠 중복은 **파츠도 보관 + 조각도 보너스**가 현재 실제 정책이다. 자동 분해라고 표현하면 틀린다. 보유 재고를 삭제하거나 보상을 몰래 줄이지 않고 실제 정책을 UI에 공개한다.
- 유닛별 파츠 풀과 전체 50종 박스는 서로 다르다. 전체 박스의 천장도 원하는 유닛 완성 보장이 아니다. 다음 1회 파츠별 확률·중복 확률·신규 합체 품질 확률을 상세에 표시한다.
- 가챠 음수 설정은 지급하지 않고 거절하며, 설정상 무료인 뽑기도 계정 잠금으로 천장·재고를 직렬화한다. 유료·무료 경로 모두 기존 계정이 필요하다.

## 통화와 공급·소모

- 운영 PP→GP: 비율 10, 수수료 5%, 1회 0.1~5 PP, 일 한도 50 PP. 실수령은 1 PP당 9.5 GP다. 동일 상점의 일부 GP/PP 비율 4보다 높아, PP 직접 구매보다 환전 후 GP 구매가 유리한 품목이 있다. GP→PP 역환전·아이템 NPC 되팔기가 없으므로 이 차이만으로 왕복 무한 이익이 생기지는 않는다. 통화별 가격을 같은 현금 가치라고 표시하지 않는다. 실제 결제를 테스트하거나 가격을 바꾸지 않았다.
- GP 생성기: 4 PP/12시간/시간당5 GP=최대60 GP, 동시 효과는1개다. 장기 공급원이며 재사용으로 효과가 중첩되어 시간당 수익이 증가하지 않는다.
- 제작 Daily OPS 보상은 배정된 미수령 미션의 일회성 공급이다. 정상 제작 시도·20회 일 제한·stack 제한·미션의 계정/당일/미수령 검사를 구분한다. 미션 반복 수령이나 무한 GP 환급으로 취급하지 않는다.
- 상점/가챠/건조/수리/강화는 GP·재료 소모 경로다. 소모품 stack은 강화 인스턴스 시장과 다르므로 상점 구매가를 그대로 거래소 매출로 계산하지 않는다.
- Lucky Charm은 승률을 바꾸지 않고 PP 당첨 지급액을 보정한다. 현재 시드 설명도 winnings다. 기본 15% house edge와 15% payout boost를 사용하는 게임은 기대 배율 0.85×1.15=0.9775(반올림/게임별 규칙 제외). 이를 당첨 보장이나 실제 플레이 수익이라고 주장하지 않는다.

## 전투 아트 판단과 적용

최신 사람 지시: 기존 로봇·외계 생물 감상용은 나쁘지 않으므로 유지한다. 전투용은 본체의 진행 방향·무기 방향·상대 진형을 읽을 수 있는 탑뷰가 기준이다. 항상 발사 중인 PNG는 실제 발사 타이밍을 읽기 어렵고 본체를 작게 만든다. 정확한 본체 + 실제 서버 발사 시 180ms/최대3px 시각 반동 + 별도 포구/탄/피격/추진 효과를 사용한다. 서버 위치·피격 판정·속도·수치에는 반동을 반영하지 않는다. 감소된 모션 환경에서는 반동을 생략한다.

감상용 원본10종, 외계 생물 전투용4종, 파츠50종은 유지한다. 총구가 카메라를 향해 들린 생성 후보는 모두 제외했다. 정면/등면이 혼합된 초상화 후보도 제외했다. 수직 위에서 본 갑옷 윗면·닫힌 투구 상판만 보이고 얼굴·가슴 정면은 보이지 않게 했다. 머리의 뾰족한 앞부분·총열·방패 방어면은 모두 같은 축을 향한다. 원본 전체를 회전해 표준 전방을 위로 맞춘512px RGBA로 저장하고, 아군/적군 전환은 본체 전체 회전만 사용한다. 위/아래 방향과64/128px 접촉 시트로 확인했다. 교체된 전투용 파일·생성 프롬프트·원본 ID는 assets/ships/top/assembly-sprite-sources.json에 기록한다. 합체 유닛을 QA 계정에 지급하거나 운영 상태를 주입하지 않는다. 보유하지 않은 유닛은 정상 도감/전투 미리보기에서 시각 확인하고, 실제 운영 지휘 검수는 소유 정규 함대로 구분한다.

## 남은 측정 한계

- 가격 정합성 검토와 단기 QA는 장기 인플레이션·D1/D7 잔존·상위 가챠와 정규 함대의 PvP 승률 증명이 아니다. 총 GP 발행/소각, 중위 재고, 재료 체결/미체결, 제작 대 직접 구매, 선택한 유닛의 완성 소요를 실제 이용자로 측정해야 한다.
- 합체 품질 보너스가 전투 수치에 반영된다. 초기 기획의 중상위/횡적 파워크리프 밴드를 실제1000전 검증했다고 주장하지 않는다. 이 변경은 품질 확률이나 기존 보유 함선 성능을 임의로 줄이지 않는다.
- 원화/코인 결제·실제 휴대폰·인간200명·모든 캠페인 장을 실제 플레이한 결과는 없다.
