# Occupy Mars — 세로 함대전 경험 복구·개선 기획

2026-10-24 · 기준 v7.500 · P0: 전투 회귀 복구. 이 문서는 몰입·작전일지 기획보다 전투 품질 게이트를 우선한다.

## 1. 목표

**함선이 주인공인 세로 전장 + 적은 수의 의미 있는 지휘 + 명확한 발사·명중·격침 피드백.**

기존 세로 탑뷰, 실제 PNG 함선, 진형과 전술, 진영 아트, 서버 전투 결과를 보존한다. 큰 글자와 큰 폼을 늘리는 것을 모바일 게임화로 간주하지 않는다. EVE 같은 풀 3D 게임으로 바꾸는 작업도 아니다.

## 4. 정보 구조와 조작 계약

### 기본 전투 화면

- 상단 42px: 전투 제목·사운드·닫기. 사운드는 사용자 선택을 유지.
- 상단 상태 52px: 아군/적군 생존·HP·경과 시간. 장문의 설명 없음.
- **중앙: 세로 전장**. 아군 아래→위, 적군 위→아래. 실제 표적 방향을 따르며 임의로 전장 방향을 돌리지 않음.
- 하단 독 112px: 전술 / 표적 / 무장. 실제 충전량, 조작 가능/불가 상태를 읽을 수 있어야 함.
- 상세 44px: 기본 접힘. 함대 역할·전술 설명·확인된 지휘 기록·고급 지휘는 필요할 때 열기.

### 행동 수

| 의도 | 조작 | 실제 반영 |
|---|---|---|
| 돌파·보호·측면 변경 | 전술 → 선택 (2탭) | 기존 지휘 명령, 서버 적용 결과 표시 |
| 적 함대 집중 | 표적 → 적 카드 (2탭), 기존 전장 탭도 보존 | 실제 함대 단위 집중 사격, 함선 저격으로 오표현하지 않음 |
| 현재 무장 발사 | 충전된 발사 버튼 (1탭) | 기존 빔/미사일/합체 명령, 실제 충전 소모 |
| 무장 바꾸기 | 무장명 → 선택 (2탭) | 선택만 변경. 선택 자체로 발사하지 않음 |
| 상태 확인 | 상세 열기 (1탭) | 읽기. 접으면 전장 시야 복구 |

리플레이/관전/연결 끊김/종료는 상태를 명시하고 지휘를 잠근다. 효과가 나왔다는 이유로 명령 적용·피해를 가정하지 않는다. 접수, 적용, 거절은 실제 응답을 표시한다.

## 5. 함선·카메라·아트

- 원본 투명 PNG와 기존 화성 지형을 유지한다. 검은 박스·빈 이미지·실패 요청을 분리 조사한다.
- 소규모 표시 길이 기준: 프리깃 48, 구축 66, 순양 90, 전함 132, 타이탄 188 CSS px 수준의 위계. 실제 화면에서 잘림/밀집을 검수해 조정하며 서버 충돌 반경·스탯은 바꾸지 않는다.
- 4척 이하에서 같은 함대의 간격만 표시상 확장해 겹침을 줄인다. 실제 진형의 상대 방향과 순서를 보존한다.
- 카메라는 생존 함선과 표시 반경이 들어오도록 부드럽게 맞춘다. 타격감 때문에 함선을 화면 밖으로 자르거나 사용자 시점을 급회전시키지 않는다.
- 함급별 크기는 같은 함종 세 척을 임의로 다르게 만드는 방식이 아니다. 혼합 함급은 연습/도감과 회귀에서 별도 확인한다.

## 6. 전투 피드백·성능

실제 shot_hit 이벤트 → 포구 섬광 → 무기 선분/탄도 → 실제 표적 위치의 명중 섬광. 실제 격침 → 폭발·짧은 흔들림. 원본 이벤트 ID 중복 제거를 유지한다. 가짜 추가 피해·격침·전투 시간 변경은 금지한다.

이벤트 입력 최대 128/프레임, 활성 선분 256, 포구 효과 96 상한을 유지한다. 큰 전투는 표시 크기와 효과 밀도를 줄이며 함급 위계를 남긴다. 화면 흔들림은 동작 줄이기 설정을 따른다. 오디오는 기존 음량/활성화와 재생 간격 제한을 따른다.

## 8. 실행·합격 게이트

1. **방향/좌표 회귀**: 적 기함 방향 재현 테스트의 수정 전 실패/수정 후 통과. 세로 위치·방향·탄도·상황도 구분 테스트.
2. **조작 회귀**: 새 독에서 전술/집중/무장 선택·발사, 잘못된 값·잠금·리플레이 차단. 서버 명령/피해 검증은 기존 실제 엔진+WS 격리 회귀.
3. **시각 미리보기**: 정상 서버의 소유 QA 전투 기록을 로컬 변경 화면에서 관찰. 미리보기와 운영 배포 증거를 구분.
4. **모바일 운영**: 정확한 커밋 배포 후 390×844, 320×740에서 실제 정상 QA 전투. 중앙 전장 390은 약 68%, 320은 약 63%를 목표로 하고 실제 치수와 영상을 남김. 조작부 44px 이상, 가로 넘침 없음, PNG/VFX 로드 실패 없음, 적/아군 방향 반대.
5. **전술 효과**: 정상 UI 명령이 서버 적용 기록과 실제 충전/피해에 연결되는지 확인. 리플레이를 실제 조작 성공으로 계산하지 않음.
6. **후속 성장**: 작전일지→전투→생산→운송→정비→방어로 복귀. 기존 가입·영토·제작 검수를 이번 전투 개편의 증거로 대신하지 않음.

출시 보고에는 배포 ID/커밋, 실제 통과 화면·조작, 남은 제한을 적는다. 물리 휴대폰, 대규모 실사용자/장기 몰입/유지율은 별도 미검증이다. 출시 완료와 재미 입증을 같은 말로 쓰지 않는다.
