# Occupy Mars — 전투 방식 비교와 권장안

작성: 2026-10-24. 의도는 3D 전환 명령이 아니라, 가능한 방식의 장단점을 비교해 이 게임에 맞는 최적안을 선택하는 것이다. 아래 권장안은 설계 판단이며 사용자 재미·리텐션이나 실제 휴대폰 성능이 입증됐다는 뜻이 아니다.

## 1. 결론

**주 전투는 세로형 함대 전술전으로 만들고, 기존 함선 아트를 활용한 고품질 2.5D 연출을 먼저 완성한다.** 지금 화면을 그대로 유지하자는 뜻은 아니다. 겹치는 HUD, 폼 같은 지휘 패널, 균일한 함급, 잘못된 방향, 종료 카메라 이동은 방식의 한계가 아니라 수정할 결함이다.

3D 함대 전술전은 다음 후보로 가치가 있다. 특히 대형함 근접 장면·포탑 추적·잔해와 조명이 필요해질 때 유리하다. 다만 전투 전체를 자유 비행으로 바꾸는 것은 별개의 게임 설계다. 직접 조종을 채택하려면 짧은 호위/요격 전투에서 먼저 조작과 성능을 비교해야 한다. 이 문서는 3D 제작·유료 서비스 사용을 확정하지 않는다.

3D 도입 여부는 모델의 멋진 정지 화면이 아니라 **같은 임무에서 표적 식별·명령 성공·전황 이해·재시도 의사·프레임 시간·발열**로 비교한다. 아직 이 비교 실험이나 실제 휴대폰 측정은 수행하지 않았다.

## 4. 지금 구현하는 전투 품질 계약

1. 아군은 아래에서 위, 적은 위에서 아래로 상대를 바라본다. 실제 기동 방향은 상대 위치에 따른다.
2. 함급 크기와 실루엣을 구분하고, 레이블은 함체를 덮지 않는다. 작은 전투와 대규모 전투의 가독성을 따로 검사한다.
3. 전술·표적·무장을 기본 3행동으로 노출한다. 무장 선택이 자동 발사가 되지 않는다. 버튼은 실제 충전/접수/적용/거절과 연결한다.
4. 포구→탄도/빔→명중→격침을 이어서 보여준다. 서버 확인 없는 피해·격침·승리 연출을 만들지 않는다.
5. 마지막 적 격침 시 카메라를 생존 함대로 강제 이동하지 않는다. 폭발은 마지막으로 보였던 함체 자리에서 끝난다. 생존 함선에 승리용 폭발/퇴장 애니메이션을 넣지 않는다.
6. 얇은 관측창 테두리와 무장 버튼 이미지를 실제 UI에 사용한다. 충전 게이지·문자·눌림은 코드로 렌더링한다. 테두리는 중앙 시야와 터치 판정을 가리지 않는다.
7. 결과는 승패→실제 참여 함선 아트→생존/손실→목표 성과/확정 보상→다음 행동. 상세 전술 수치는 접어서 제공한다. 관전 승자·무승부·내 패배를 구분한다.
8. 메인은 같은 높이의 터치 컨트롤, 헤더/시즌/공지의 별도 행으로 정리한다. 320/390에서 교차 여부를 실제 화면으로 검사한다.

## 5. 영토와 우주 전투를 하나의 게임으로 만드는 구성

핵심 흐름은 **영토 확보 → 생산·수확 → 재료 운송 → 제작/수리·함대 편성 → 거점/수송로 공격·방어 → 영토와 보급 변화**다. 캠페인은 이 흐름에 목적과 등장 인물을 주고, 퀘스트는 실제 행동 기록을 읽어 진행한다. 보상 숫자만 누르는 별도 목록이 되어서는 안 된다.

| 영역 | 플레이어의 질문 | 반드시 연결할 결과 | 현재/후속 구분 |
|---|---|---|---|
| 작전일지 | 지금 무엇을 왜 해야 하나? | 한 개의 현재 목표, 선행 조건, 보상, 다음 목적지 | v7.501 기본 연결 구현. 신규 계정 연속 플레이 검증 중 |
| 영토 | 이 땅이 왜 필요한가? | 생산 재료·거점·방어 대상과 소유 정보 | 기존 소유/수확/생산 경로 보존. 실제 모든 영토 유형의 가치 균형은 추가 측정 |
| 경제 | 생산품을 어디에 쓰나? | 개인 재료/전선 정비 창고를 구분하고 수리/제작으로 이동 | 재료 안내 연결 구현. 장기 공급/수요·과잉 생산 미검증 |
| 함대 | 무엇을 준비하고 지켜야 하나? | 역할·함급·장비·손상→적 임무에 맞춘 편성 | 기존 역할·서버 전술 유지. 새로운 상성/숫자 밸런스를 임의 변경하지 않음 |
| 전투 결과 | 이겨서 세계가 어떻게 바뀌었나? | 실제 목표 성과·손실·보상·다음 거점/수리 | 결과 UI 개선. 서버가 확정하지 않은 자동 영토 점령은 표시하지 않음 |
| 길드·경쟁 | 누구와 무엇을 두고 싸우나? | 공동 거점·수송·방어·시즌 목표 | 기존 시스템 유지. 실제 인구 밀도/대규모 전쟁 검증 없음 |

EVE/리니지 같은 몰입은 메뉴의 양이나 그래픽만으로 만들 수 없다. 보급로를 지키는 이유, 잃을 수 있는 가치, 동료와의 역할, 승리 이후의 세계 변화가 연결돼야 한다. 다만 새 결제·풀로스·초보 약탈을 이 변경에 임의 도입하지 않는다. 초보는 무료 함대와 안전한 작전으로 선택의 결과를 배운 뒤 경쟁에 들어간다.

## 6. 3D가 필요해질 때의 구체적인 연결안

가능하다. **Tripo 또는 Meshy 중 하나만 연결하면 충분하며 둘 다 필수는 아니다.** 선택 기준은 우리 원본 함선 실루엣 보존, 후면/하부 형상, 텍스처 품질, 저폴리 출력, 예산 내 반복 제작이다. 아직 동일 입력으로 두 서비스의 생성 결과를 비교하지 않았으므로 품질 우열을 단정하지 않는다.

- [Meshy 공식 게임 에셋 문서](https://docs.meshy.ai/en/webapp/guides/use-cases/game-assets)는 이미지/텍스트 생성 뒤 Remesh로 목표 폴리곤 수 조정, PBR 텍스처, 웹용 GLB 내보내기를 안내한다. 문서의 인체 리깅 예시는 정적 우주선에 필수인 단계가 아니다.
- [Tripo 공식 편집 API 문서](https://platform.tripo3d.ai/docs/editing)는 Smart LowPoly와 face_limit 조절을 설명한다. 웹 런타임용 GLB 출력과 실제 생성 모델 상태를 확인해야 한다. 자동 생성 결과는 곧바로 게임 최적화 완료가 아니다.
- 입력: 보유 원본 함선 이미지, 함종별 크기 기준, 정면/측면/후면 설계 시트. 출력: 내보낸 GLB+PBR 이미지+라이선스/생성 설정. 웹 서비스에서 직접 생성 후 파일로 전달하는 방법도 가능해 API 연결이 필수는 아니다.
- API 자동화를 선택하면 공식 계정/커넥터 또는 로컬 비공개 환경 설정으로 연결한다. 키를 채팅이나 공개 프런트엔드에 넣지 않는다. 연결 전까지 새 유료 생성은 실행하지 않는다.
- Blender에서 중심점·축·미터 스케일·법선·UV·분리 포탑/엔진 노드·LOD를 정리한다. 정적 함체는 스켈레톤 없이도 렌더링 가능하다.

**비교 샘플:** 아군 요격함, 적 프리깃, 대형 기함 총 3종. 전 함선을 먼저 3D화하지 않는다. 같은 호위 임무를 2.5D/3D 전술전으로 보여주고, 직접 조종은 별도 짧은 분기로 비교한다.

초기 제안 예산(실측값 아님): 일반 적 3–5천 삼각형, 주연 8–12천, 원거리 LOD는 1/4 이하; 일반 512px/주연 1K 텍스처; 함종당 1–2재질; 초기 추가 다운로드 8MB 이내; 중급 실제 휴대폰 30fps 유지. 장면 개체 수·GPU·해상도에 따라 다시 조정하며 이 수치만으로 성능을 보증하지 않는다.

## 7. 출하 및 다음 선택 기준

이번 릴리스: 메인 겹침·전투 종료·폭발 자리·결과 화면·이미지 스킨과 기존 전투/일지 흐름을 수정하고 회귀/운영 화면을 검증한다. **3D 게임 구현 완료나 직접 조종 가능으로 표시하지 않는다.**

3D 전술전 채택 조건: 같은 함대/같은 임무에서 식별성과 조작이 나빠지지 않고, 실제 휴대폰 성능·발열·다운로드 기준을 충족하며, 사용자 평가에서 입체 연출의 이득이 확인될 것. 직접 조종 채택 조건은 여기에 터치 회피/조준 재미, 전술 모드 복귀, 서버 판정 및 영토 결과 연결까지 추가한다.

## 신규 계정에서 확인한 장비 준비 경로

5작전 완료·수확 뒤 보상 조회 전에는 레벨1/GP10.519였다. 기본 제작은50GP이며 NPC 연습전 자체는 GP/광물 무보상이다. 기록에서 자격 있는 업적 평가와 출석8GP 수령 뒤 실제 잔액68.519를 확인했다. 완료 일지에서 기록·정상 보상 확인을 우선하고 GP·개인 재료를 확인해 장비를 준비한다. NPC는 무보상 훈련으로 명시한다. 경쟁 레벨·보상정책·가격·성공률은 바꾸지 않는다. 업적 평가 뒤 화면 잔액을 서버와 동기화한다.

## 아트 용도 구분

함대전에서 위치·방향을 읽는 정사영 탑뷰와, 상세/건조/결과에서 부피·재질을 읽는3/4뷰를 분리한다. 기존 ships/reveal의 동일 함선3/4뷰를 결과에 재사용(v7.505). 전투 스프라이트를 제거하거나 전면3D 전환으로 해석하지 않는다.

## v7.507 검수 정정

NPC 연습전 자체는 GP/광물 무보상이다(anti-mint 정책). 앞선 NPC 보급 보상 가정은 폐기한다. 완료 일지→기록·자격 있는 출석/완료 과제/업적 보상 확인→실제 GP·개인 재료 확인→제작으로 연결한다. NPC는 무보상 훈련으로 명시하고, PvP 해금·경제/성공률은 보존한다. 업적 평가 뒤 잔액을 서버에서 갱신한다.
