# 영토 점령과 50~100척 연합전 개선 — v7.513

2026-10-28 시작, 2026-10-29 마무리. 범위는 영토 선택/점령 동선과 실제 함대전 엔진·표현·지휘다. 기존 함선 아트와 경제를 보존한다.

## 기획 판단

영토는 면적 숫자를 늘리는 것만으로는 오래 재미있기 어렵다. 현재 구현된 **위치·진입 조건 확인 → 소유 → 생산/GP·광물 수확 → 함선 준비/정비 → 전선 목표와 방어**의 연결을 유지하는 것이 맞다. 처음부터 잠긴 코어에 배치해 실패하게 하거나, 손가락을 움직여도 선택지가 움직이지 않으면 이 연결에 진입하기 전에 이탈한다. 이번 변경은 그 마찰을 제거한다. 추가 화폐/새 건물/새 전투 모드는 도입하지 않는다.

100척을 100번 터치하는 방식은 모바일에 맞지 않는다. **내 함대 선택 → 접근 교리/상대 함대 선택 → 이동·정지/자동 복귀 → 충전 무기**를 지휘 단위로 유지한다. 다수 함대와 함선의 실제 수·HP·손실은 서버가 유지하고, 화면은 척수에 따라 정보 밀도를 낮춘다. 모든 선체를 그리되 기함·현재 지휘 함대·집중 표적이 먼저 읽혀야 한다. 수동 지휘가 자동보다 무조건 유리하다고 설계하거나 검수하지 않는다.

## 확인한 결함과 구현

- 모바일 드래그가 매 이벤트마다 작은 이동을 버렸다. 누적 좌표를 격자에 투영하고 핀치/종료 시 이전 손가락 상태를 지운다.
- 극지 경계가 중심점만 제한되거나 실제 .22° 대신 .1°로 검사됐다. 배치/크기 변경/확정이 같은 격자와 사각형 전체 경계를 사용한다.
- 320px 조작부 240px 안에 264px 콘텐츠가 넘쳤다. 64px 크기 조이스틱과 두 줄 버튼으로 정리하고 확인/취소는 44px 이상. 서버가 허용하던 1×1도 모바일에서 선택 가능하다.
- 초보 무료 구역 선택이 확정 모달의 실패 안내 뒤에 숨어 있었다. 신규 자격을 정상 조회한 사용자에게 지도 선택 단계부터 바로 제공한다. 무료 여부/빈 땅/진입 조건/비용은 서버가 다시 확인한다.
- 다중 소유자 중 침공 미리보기가 첫 소유자를 택했다. 겹친 픽셀 수 최다 소유자를 택하고, 다른 선택지로 바뀐 뒤 도착한 이전 조회 응답은 무시한다.
- 6번째 이후 연합 함대가 양쪽 공통 중앙에 생성됐다. 6개 이상부터 각 진영의 고유 배치 칸을 사용한다. 기존 1~5함대 시작 배치는 보존한다.
- 대전에서 소형 함선 절반을 생략하던 렌더 분기를 제거했다. 같은 프레임의 화면 크기 재측정도 함선마다 하지 않는다.
- 600척에서 선체보다 큰 엔진 불꽃·HP막대·함대 이름이 겹쳤다. 함급 비율을 유지하며 밀도에 따라 선체 최소 크기를 조절하고, 80척 초과에서는 기함의 불꽃/HP와 선택/표적 함대 라벨을 우선한다. 탄착·빔·미사일·폭발은 기존 서버 이벤트와 제한량을 유지한다.
- 내 함대가 둘 이상이면 함대 선택판에서 이름·생존 척수·HP를 보고 전환한다. 전환 자체는 공격 명령이 아니다. 관전/리플레이와 외부 소유 함대는 지휘할 수 없다.
