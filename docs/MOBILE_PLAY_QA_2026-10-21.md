## 증거 범위

Chrome 터치 390×844와 WebKit 터치 320×568에서 localhost 실제 전체 서버·PostgreSQL·WebSocket으로 조작했다. Chrome의 추가 신규 계정은 360×640이며 가로844×390도 확인했다. API 응답 고정 더미·시각/잔액/플레이 진행 주입 없이 정상 가입과 서버 보상으로 진행했다. WebKit은 자동화 브라우저 엔진이며 물리 iPhone 검수는 아니다. 운영 계정·메일·체인·결제·운영 보안키를 변경하지 않았다. 원본 화성·메인 메뉴·함선/아이템 아트는 유지했다.

실제 가입 계정 2개는 격리 테스트 계정이다. 기존 MiroFish run03의 고유 OM001–OM200 가상 텍스트 인터뷰와 구분한다. 200개 모두 현재 소스에 대조했고, 사람이 현재 앱을 플레이한 조사나 매출·리텐션 검증으로 표시하지 않았다. 새 유료 모델 실행은 없다.
