# OCCUPY MARS — P2E 강조 전략 진단 (2026-05-28)

> 4 페르소나 병렬 진단(그로스·게임경제학자·법무·비판검토자) 종합. 결론: **"P2E (Play-to-Earn)" 직접 마케팅은 위험. "P2O (Play-to-Own)" 프레임으로 전환**.

## 핵심 결론 (4명 합의)

운영자 요구는 "P2E를 강조"였으나, 4 페르소나 전원이 직접 P2E 카피에 반대한다:

- **법무**: 가챠+환금 결합 = 도박 분류(벨기에·네덜란드 금지, 한국 게임위 등급 거부 사유). "수익·돈 번다" 카피는 SEC Howey 투자계약·EU MiCA·한국 게임산업법(환전알선) 트리거. 3단 추천은 MLM/피라미드 분류 위험.
- **경제학자**: P2E 노출 = 출금 압력↑·시빌/봇 ROI 역전·마켓 덤프 연쇄·페그 디펜스 비용. Axie/STEPN 경로 답습 가능.
- **그로스**: "번다" 약속은 봇/한탕러 자석. 의미있는 유저는 "자산 가치"에 반응.
- **비판검토자**: 체인 미가동 + P2E 카피 = 허위광고 + 약속-실제 격차 worst-case. 런칭일 redemption rush로 솔벤시 가드 무력화 가능.

## P2E → P2O 프레이밍 전환

| 위험 (P2E) | 안전 (P2O) |
|---|---|
| "Earn money / 돈 번다 / 수익 보장" | "Own / Collect / Trade / 소유" |
| "Guaranteed earnings / ROI / 일당 $X" | "On-chain · Tradable assets" |
| "환금 가능" (체인 미가동 시) | "Pegged ~$1 · Redeemable at mainnet launch" |
| "더 비싼 함선을 얻어라" | "더 강한 함선 = 경쟁 우위" |
| "Investment / Passive income" | "Strategic Mars colonization game" |

## 실행 권고

### ① 메시징 카피 (4언어 안전 표현)
- **쓸 수 있음**: Play · Collect · Trade · Own / On-chain assets / Pegged / Strategic colonization
- **절대 금지**: Earn money, Guaranteed, ROI, Investment, Risk-free, 일당, 수익 보장

### ② 자산 가시화 (구현됨 — v7.161)
- `🪐 MY MARS PORTFOLIO` 모달: 함선·영토·PP·USDT를 **자산 수량**으로 표시(수익률·일당 환산 0).
- 환금 잠재가치는 `🔒 잠금` 상태 + "Base 메인넷 컨트랙트 가동 시 활성" 디스클로저(법무 권고 직접 반영).
- P2O 3-스텝 설명(채굴/수집/거래) — "벌어라"가 아닌 "쌓인다·소유한다".

### ③ 추가 가드 (경제학자 권고 — 차후 적용 대기)
- **출금 일일 글로벌 캡**: treasury 7d MA의 60% 상한

- **PP 출금 단계별 수수료**: 0–100PP 5%, 100–1000 10%, 1000+ 15%
- **마켓 수수료 동적화**: 거래량 급변 시 자동 상승(덤프 마찰)

### ④ 필수 컴플라이언스 (법무)
- **지오펜싱**: 미국·중국·한국·벨기에·네덜란드 (IP/지갑) — ToS 명시
- **연령 게이트 18+** + KYC + AML 모니터링
- **확률 공개** (한국 2024 확률공개법 — 가챠 OK, 이미 구현됨)
- **체인 미가동 디스클로저**: 메인·온보딩·가챠·지갑 모달(이미 포함됨)
- 면책: "In-game assets only. No guaranteed earnings. See Terms."

### ⑤ 비판검토자 핵심 경고
- "단계적 환금" 마케팅은 약속의 누적 부채를 만든다 — 런칭 지연 시 매 연기마다 신뢰 재청구.
- 컨트랙트 배포·감사·소량 실거래 검증 이전엔 환금 카피 0. 가동 후 사후 발표가 가장 안전.

## 결론 한 줄

> **"P2E"를 마케팅하지 말고, "P2O = 자산 소유 + 거래 가능한 깊은 화성 식민지 전략 게임"으로 포지셔닝하라. 환금은 가동 후 발표.**
