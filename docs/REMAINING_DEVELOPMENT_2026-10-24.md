# Occupy Mars — 남은 개발 실행 범위

2026-10-24 사람 지시: 남은 개발 진행, 함대 전술전 포함. 기준 운영 v7.507/e2bcc914. 전면 3D 전환은 요구되지 않았으므로 기존 세로형 2D/2.5D 함대전을 확장한다.

## 구현과 완료 기준

1. **재료 제작의 가치:** 같은 소모품을 구매보다 훨씬 많은 GP와 재료로 확률 제작하던 옛 기본 레시피를 확정 재료 변환으로 정리한다. GP 조립비는 0, 실패 없음. 재료의 현재 NPC 소매 묶음 단가와 출력 직접 구매가를 비교하며, 이것을 플레이어 시장 체결가로 가정하지 않는다. 기존 상품 가격·보유 자원·지급 이력·일일 보상은 보존한다. 운영자가 수정한 레시피는 덮어쓰지 않는 조건부 마이그레이션을 사용한다. 수량 한도·동시성·잘못된 레시피·중복 차감 회귀를 검증한다.
2. **실제 함대 전술전:** 자기 함대를 전장에서 선택하고 지점 이동/제자리 방어/자동 지휘 복귀를 지시한다. 기존 진형·기동·집중·충전 무장과 함께 동작한다. 서버의 소유권·좌표 검증·이동 속도·경계·피해 판정이 권위이며 화면만 움직이는 방식은 사용하지 않는다. 이동 표시는 서버가 받은 경로와 일치하고 관전/리플레이/종료/연결 끊김에서 명령을 잠근다. 기존 아트·세로 방향·함급 크기를 유지한다.
3. **퀘스트·보상 연결:** 기존 캠페인 목표·선행 조건·보상 경로를 확인한다. 실제 지급과 서사 기록을 구분하고, 없는 효과나 무한 공급을 약속하는 안내를 제거한다. 실제 지급 가능한 보상과 수령 후 확인 동선을 연결한다. 전체 대사나 아트를 재작성하지 않는다.
4. **실제 검수·배포:** 격리 엔진/WS·경제/동시성·캠페인·7언어·모바일 검사 후 정확한 커밋을 배포한다. 정상 소유 QA 계정으로 실제 이동/집중/방어·제작/보유함·캠페인 진입을 확인하고 320/390 화면과 영수증을 남긴다. 운영 재화 지급·시간 변경·게임 상태 주입으로 통과시키지 않는다.

## 제약과 산출물

기존 데이터·승인1000MB·TOTP비활성·비밀값·무관한 사용자 변경 보존. 출력은 기존 검수 폴더의 remaining-work 하나만 사용하며 전체 소스 아카이브는 복제하지 않는다. 로그10개/10MiB, 스크린샷16개, 전체40MiB 예산. 삭제0.

물리 휴대폰·실제 다수 이용자·D1/D7 재미/유지율은 개발 완료나 브라우저 검사로 대체하지 않는다. 3D 함대전은 기존 비교안의 선택 후보이고 직접 조종은 별도 모드다.

## 실제 위치가 전술에 미치는 영향

이동이 표시 전용 기능이 되지 않도록 일반 사격의 거리와 표적의 실제 측후방 각도가 피해 계수에 반영된다. 일반350/미사일480/레이저·저격550/폭격220 서버 좌표 단위의 soft envelope를 사용하고 최종 계수는0.85–1.18로 제한한다. 저격은120미만 근접에서 불리하다. 범위 밖에서도 발사는 계속된다. 혼합 함대의 원은 생존 함선의 평균 안내값이며 개별 무기의 하드 발사 제한이 아니다. 수동 충전 무장은 기존 서버 규칙을 유지한다. 이 수치는 게임 설계의 초기 튜닝이며 물리 사거리나 장기 밸런스 검증값이 아니다.
