# OCCUPY MARS — 경제 v2: 땅=입금전용 + 함선 F2P (2026-05-29)

> 사장 결정. `docs/ECONOMY_TOKEN_POLICY_2026-05-29.md`(담보-룸 환매)의 후속·상위 설계.
> 핵심: **PP는 입금에서만 나오는 가치토큰(땅 구매 + USDT 환매), GP는 F2P 게임 통화(함선으로 벌고 게임에 씀).**

---

## 0. 왜 이렇게 가나
- 땅(영토)은 **유한 자원**이다. 무입금 유저에게 공짜 PP를 주고 땅을 사게 하면, 땅이 소진된 뒤 신규 무입금 유저에게 줄 땅이 없다.
- 따라서 **땅은 입금 유저 전용**으로 한다(PP=입금 연동 / USDT 결제).
- 무입금 유저는 **함선**으로 논다: 재료 채굴→GP, 함선 일일퀘/OPS, 전투. GP는 게임 안에서만 쓰이고 환매 불가라 누수 없음.

## 1. 투트랙 경제

| | 무입금 유저 (F2P) | 입금 유저 |
|---|---|---|
| 통화 | **GP** | GP + **PP** |
| PP 출처 | 없음(무료 PP 폐지) | 입금 보너스(chain.js) |
| 핵심 루프 | 함선 재료채굴→GP, 일일 OPS, 전투 | + 영토 소유/채굴/공성 |
| 땅 | ❌ 구매 불가 | ✅ PP(입금연동)/USDT |
| 현금화 | 없음 | PP→USDT (담보-룸 한도 내) |

- **PP = 입금 전용 가치토큰.** 용도: 땅 구매 + USDT 환매. 무료 지급 안 함.
- **GP = F2P 통화.** 함선 채굴·일일퀘·전투·미션으로 획득. 모든 게임 소비에 사용. **환매 불가** → 무한 발행돼도 USDT 누수 없음.
- redeemable_pp 게이팅(mig 271)은 그대로 유지 → 혹시 남는 PP도 입금분만 환매 가능(방어 심층).

## 2. 단계 계획

### P1 — 땅 = 입금 전용 게이팅 (본 커밋)
- 클레임 PP 결제를 `redeemable_pp`(입금 연동 잔액)로만 허용. 무입금 유저(redeemable_pp=0)는 PP로 땅 못 삼.
- USDT 결제는 그대로(입금자만 USDT 보유).
- 튜토리얼 무료 첫 클레임(`onboarding_free_claim_enabled`)은 설정으로 유지(끄면 완전 입금 전용). 신규 유저 1회 맛보기.
- 설정 `land_requires_deposit_pp`(기본 true)로 토글.
- 재사용: `users.redeemable_pp`, `clamp_redeemable_pp` 트리거(mig 271).

### P2 — 무료 PP → GP 전환 (×10, 후속)
- 비입금·비하이잭 PP 보상을 GP(×PP→GP 환율 10)로 전환. 가치 보존.
- 대상: 가입(auth), 레벨업(db.js), 채굴 harvest(api.js), 퀘스트, 미션, 탐험, 온보딩, 일일, 로켓, 시즌.
- 유지(PP): 입금 보너스(chain.js), 하이잭 등 땅-PvP 내부 PP 환불/보상(닫힌 루프, redeemable 게이팅으로 비환매).
- PP로 가격 매겨진 비-땅 소비처(실드/미션발동/탐사/이름변경/POI힌트 등)는 GP 결제 추가 또는 GP로 재명명(별도 점검).

### P3 — 함선 F2P 엔진 (신규 기능)
- **함선 재료 채굴→GP**: 현재 재료 드롭은 영토 harvest 전용(api.js:3381 `rollResourceDrop`). 땅 없이 함선으로 재료/GP를 버는 경로 신설(expedition.js/dailyOps 확장 또는 신규).
- **함선 일일퀘/OPS 확대**: dailyOps.js 확장 — 무입금 유저의 일일 GP 수급 루프.
- 별도 설계 문서/스프린트.

## 3. 정합성 체크
- 누수 방어: GP는 환매 불가 + 무료 PP 폐지 + redeemable 게이팅 → 무료 가치가 USDT로 새지 않음.
- F2P 보존: 함선 루프(채굴/일일퀘/전투)로 무입금도 플레이 가능. 땅만 유료.
- 입금 동기: 땅 소유·공성·PP 환매가 입금 보상.

## 4. 잔여 리스크
- P3(함선 F2P 엔진)이 충분히 재미있고 GP 수급이 적절해야 무입금 유저가 이탈 안 함. 함선 루프가 빈약하면 "땅 못 사니 할 것 없다"가 됨 → P3가 실질 성패.
- GP ×10 전환은 GP 인플레를 키움(GP는 무캡). 게임 내 GP 가격도 함께 재튜닝 필요(admin settings). 환매 불가라 USDT 리스크는 없음.
