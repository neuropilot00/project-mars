# OCCUPY MARS — 경제 v2: 땅=입금전용 + 함선 F2P (2026-05-29)

> 사장 결정. `docs/ECONOMY_TOKEN_POLICY_2026-05-29.md`(담보-룸 환매)의 후속·상위 설계.
> 핵심: **PP는 입금에서만 나오는 가치토큰(땅 구매 + USDT 환매), GP는 F2P 게임 통화(함선으로 벌고 게임에 씀).**

---

## 0. 왜 이렇게 가나 (확정 모델)
- 땅(영토)은 **유한 자원**. 무입금 유저에게 공짜 PP를 줘 땅을 사게 하면 땅 소진 후 신규 유저에게 줄 땅이 없다.
- 그렇다고 무입금 유저의 PP 땅 구매를 **하드락하지 않는다**(과한 제약). 대신 **사다리**를 준다:
  무입금 = 재료 수급 계층(함선 채굴→GP) → 경매장에서 **GP로 PP를 사서**(유저끼리) → 프론티어 땅 구매 → 땅에서도 재료 획득 → 상위 섹터로. 올라갈 명분/이유를 경제가 제공.
- **닫힌 계의 핵심 규칙**:
  · **PP→GP**: 게임 내 지원(일방향, 기존 `/exchange/pp-to-gp`).
  · **GP→PP**: 게임 내 **금지**. 오직 **경매장에서 유저끼리(P2P)**. 운영자는 GP로 PP를 절대 발행하지 않음.
  · 따라서 **PP 총량 = 입금량으로 고정**(모든 PP가 실입금 담보로 뒷받침). 무료 PP 없음(전부 GP로).
  · 이 덕분에 **PP→USDT 출금 한도를 80%까지** 열어도 안전(20%는 영구 게임 내 버퍼/마진).

## 1. 투트랙 경제

| | 무입금 유저 (F2P) | 입금 유저 |
|---|---|---|
| 통화 | **GP** | GP + **PP** |
| PP 출처 | 없음(무료 PP 폐지) | 입금 보너스(chain.js) |
| 핵심 루프 | 함선 재료채굴→GP, 일일 OPS, 전투 | + 영토 소유/채굴/공성 |
| 땅 | PP/USDT로 구매 가능(PP는 경매장서 GP로 구입) | ✅ PP/USDT 직접 |
| 현금화 | (경매로 산 PP는 게임용; 출금은 입금분) | PP→USDT 최대 80% (담보-룸 한도 내) |

- **PP = 입금 발행 전용 가치토큰.** 출처: 입금(chain.js)뿐. 용도: 땅 구매 + USDT 환매. 무료 faucet 없음(전부 GP).
- **GP = F2P 통화.** 함선 채굴·일일퀘·전투·미션으로 획득. 모든 게임 소비. **환매 불가** → 무한 발행돼도 USDT 누수 0.
- **GP↔PP 다리 = 경매장(P2P)만.** 무입금 유저는 GP로 PP를 사서 땅 구매. 운영자는 GP→PP 발행 안 함.
- redeemable_pp 게이팅(mig 271) 유지 → USDT 출금은 **입금 origin PP의 80%**까지. 경매로 산 PP·게임 PP는 게임용(환매 버킷 미적립).

## 2. 단계 계획

### P1 — 땅 하드락 철회 (완료/원복)
- 초안의 "PP 땅 결제 = redeemable_pp 전용 하드락"은 **철회**(과한 제약). 땅은 PP/USDT로 누구나 구매.
- 클레임 코드는 원복(전체 pp_balance 결제). redeemable_pp 는 트리거가 pp_balance 감소에 맞춰 자동 클램프.
- 설정 `land_requires_deposit_pp`(mig 272)는 inert(코드 미참조, 예약). 무입금 봉쇄는 안 함 — 사다리로 대체.

### P2 — 무료 PP → GP 전환 (×10) [핵심·필수]
- 모델 정합성의 핵심. 모든 비입금 PP faucet → GP(×PP→GP 환율 10, 가치 보존). PP 총량을 입금량에만 묶음.
- 대상: 가입(auth), 레벨업(db.js), 채굴 harvest(api.js), 퀘스트, 미션, 탐험, 온보딩, 일일, 로켓, 시즌, **바운티(governance.js:389 GP→PP 전환 제거→GP 보상)**.
- 유지(PP): 입금 보너스(chain.js). 하이잭 등 땅-PvP 내부 PP 환불/보상은 닫힌 루프라 유지 가능(환매 버킷 미적립이라 비환매).
- PP로 가격 매겨진 비-땅 소비처(실드/미션발동/탐사/이름변경/POI힌트)는 GP 결제 추가 또는 GP 재명명(점검).

### P3 — GP↔PP P2P 경매 + 자산 경매 (GP/PP) [신규, 기존 인프라 재사용]
- **재사용**: `auctionCombat.js`가 이미 `currency`별 bid/buyout(`deductBalance/addBalance(wallet, currency, amt)`). PP/GP currency 지원 확장.
- **GP↔PP 거래소형 경매**: 유저가 PP를 GP 가격에 매물(또는 GP를 PP 가격에) → 무입금 유저가 GP로 PP 구입. 운영자 GP→PP 발행 없음.
- **함선·영토 경매**: GP 또는 PP로 입찰/즉구. 자산 유동성.
- 경매로 취득한 PP는 **환매 버킷(redeemable_pp) 미적립** → 게임/땅 용도. (출금은 입금 origin만.)

### P4 — 출금 한도 80% 적용
- PP=입금 발행 전용이 보장된 뒤, USDT 출금을 입금 origin PP의 **80%**까지 허용(`pp_withdrawable_pct=80`). 20%는 영구 버퍼.
- 구현: 입금 시 `redeemable_pp += ppBonus × 0.8`(현 100%→80%). swap 게이트는 기존 redeemable_pp 캡 유지.

### P5 — 함선 F2P 엔진 (신규 기능)
- **함선 재료 채굴→GP**: 현재 재료 드롭은 영토 harvest 전용(api.js:3381). 땅 없이 함선으로 재료/GP 버는 경로 신설.
- **함선 일일퀘/OPS 확대**: dailyOps.js 확장 — 무입금 유저 일일 GP 수급. F2P 사다리의 1단.

## 3. 정합성 체크
- 누수 방어: GP는 환매 불가 + 무료 PP 폐지 + redeemable 게이팅 → 무료 가치가 USDT로 새지 않음.
- F2P 보존: 함선 루프(채굴/일일퀘/전투)로 무입금도 플레이 가능. 땅만 유료.
- 입금 동기: 땅 소유·공성·PP 환매가 입금 보상.

## 4. 잔여 리스크
- P3(함선 F2P 엔진)이 충분히 재미있고 GP 수급이 적절해야 무입금 유저가 이탈 안 함. 함선 루프가 빈약하면 "땅 못 사니 할 것 없다"가 됨 → P3가 실질 성패.
- GP ×10 전환은 GP 인플레를 키움(GP는 무캡). 게임 내 GP 가격도 함께 재튜닝 필요(admin settings). 환매 불가라 USDT 리스크는 없음.
