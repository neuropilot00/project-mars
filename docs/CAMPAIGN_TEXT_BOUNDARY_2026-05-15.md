# OCCUPY MARS — Campaign Text Boundary

> Date: 2026-05-15  
> Goal: 캠페인 대사/스토리는 보존하고, **수정 가능한 UI 가이드 문구 범위**만 명확히 분리한다.

---

## 1. 결론

캠페인에서 바꿔도 되는 건 **스토리 본문이 아니라 행동 유도 UI 문구**다.

즉:
- **보존 대상** = 대사, 브리핑 본문, 캐릭터 말투, 스토리 서사
- **수정 가능 대상** = 목표 요약, 이동 라벨, 진행 경고, 결과 확인 버튼 등 시스템 안내 카피

---

## 2. 절대 건드리면 안 되는 영역

아래는 캠페인의 **서사/연출 본문**이므로 보존한다.

### 2.1 챕터 제목/스토리 텍스트
코드 근거:
- `index.html:28030-28039` `_campaignStoryText()`
- `index.html:28083-28100+` `showCampaignStory()`

의미:
- 서버/스토리 데이터에서 내려온 챕터 제목
- 대사 라인
- 장면 텍스트
- 스토리 분기 텍스트

여긴 손대면 안 된다.

### 2.2 캐릭터 이름/화자 표시
코드 근거:
- `index.html:28041-28050` `_campaignStorySpeakerName()`

의미:
- 스토리 화자명 표기
- 인물의 정체성과 말투에 연결되는 부분

여긴 로컬라이징 정정 외엔 건드리지 않는다.

### 2.3 브리핑/결과용 서사 문장
코드 근거:
- `index.html:28966-28969` `showCampaignResult()`
- `ch.briefing`, `campaign_result_npc_success`, `campaign_result_npc_failure`

의미:
- NPC가 말하는 결과 대사
- 브리핑 내 서사적 맥락

이건 시스템 설명보다 세계관/연출에 가깝기 때문에 보존한다.

---

## 3. 바꿔도 되는 영역

아래는 **행동 유도 / 상태 안내 / UI 보조 카피**라서 수정 가능하다.

### 3.1 목표 이동 라벨
코드 근거:
- `index.html:27964-27979` `campaignObjectiveActionLabel()`

현재 예시:
- `내 영토`
- `조선소`
- `함대`
- `전투`
- `마켓`

이건 대사가 아니라 **어디로 가면 되는지** 알려주는 UI 라벨이다.  
재미 기준/EVE Lite 기준에 맞춰 더 명확하게 다듬어도 된다.

예:
- `내 영토` → `영토 관리`
- `전투` → `함대전 진입`

단, 지금 단계에서는 큰 개명보다 **행동 명확화**만 한다.

### 3.2 목표 진행용 안내 토스트
코드 근거:
- `index.html:27985-28003` `handleCampaignObjectiveAction()`

현재 예시:
- `내 영토에서 목표를 진행하세요`
- `PVP 탭에서 함대전을 시작하세요`

이건 완전히 **시스템 안내용 보조 문구**다.  
스토리 훼손 없이 수정 가능하다.

### 3.3 목표 부족 경고 문구
코드 근거:
- `index.html:28913-28924`
- `campaign_objectives_gate`
- `campaign_objectives_gate_sub`

현재 역할:
- 남은 목표가 있어서 작전 완료가 안 되는 상태 설명

이건 서사가 아니라 **진행 차단 이유 설명**이다.  
더 짧고 행동 중심으로 바꿀 수 있다.

### 3.4 진행률/상태 라벨
코드 근거:
- `index.html:28909-28912`
- `campaignStatsHtml()` (`index.html:27930-27939`)

현재 예시:
- `작전 진행률`
- `남은 시간`
- `경과`
- `STATUS`

이건 완전히 시스템 메타정보라 수정 가능하다.

### 3.5 카드 버튼 레이블
코드 근거:
- `index.html:27864-27896`

현재 예시:
- `시작`
- `계속`
- `결과`
- `잠김`
- `재도전`

이건 스토리가 아니라 **카드 액션 버튼**이라 수정 가능하다.

### 3.6 목표 라벨 자체
코드 근거:
- `index.html:27941-27958` `campaignObjectivesHtml()`
- 실제 표시값: `_campaignStoryText(o.label) || o.labelKo || o.label || o.id`

중요:
- 여기서 `o.label`이 **스토리 데이터 안의 목표 문장**이면 함부로 바꾸면 안 된다.
- 하지만 별도 UI fallback 문구나 action suffix를 붙이는 건 가능하다.

즉:
- **목표 본문 자체**는 조심
- **주변 행동 라벨/버튼/진행 안내**는 수정 가능

## 4. 지금 당장 손대도 안전한 후보

### 우선순위 A — objective action label
위치:
- `index.html:27964-27979`

이유:
- 스토리와 분리돼 있음
- 행동 유도력이 높음
- 초반 30분 흐름 개선에 직접 영향

### 우선순위 B — action toast
위치:
- `index.html:27985-28003`

이유:
- 유저가 다음 행동을 이해하는 데 중요
- 대사/브리핑과 무관

### 우선순위 C — objective gate warning
위치:
- `index.html:28913-28924`, `28945-28950`

이유:
- 왜 완료가 안 되는지 더 직관적으로 설명 가능
- frustration 감소 효과 큼

### 우선순위 D — campaign card button label
위치:
- `index.html:27864-27896`

이유:
- 스토리 훼손 없음
- 시작/계속/재도전 흐름 정리가 쉬움

---

## 5. 지금은 건드리지 말아야 하는 것

- 챕터 제목
- 브리핑 본문
- 씬 대사
- 캐릭터 이름
- 스토리 선택지 문장
- 결과 화면의 NPC 감정 문장

이건 캠페인의 **콘텐츠 본체**다.

---

## 6. 실제 작업 원칙

1. 캠페인 **스토리 데이터는 보존**
2. `index.html`의 **행동 유도 카피만 수정**
3. 목표 본문을 건드리기보다
   - 이동 라벨
   - 토스트
   - 경고 문구
   - 버튼 텍스트
   위주로 정리
4. 모든 수정은 **첫 30분 흐름 개선**에 연결될 때만 수행

---

## 7. 한 줄 요약

**캠페인 대사는 건드리지 않는다.**  
**바꾸는 건 캠페인 바깥의 행동 유도 UI 문구뿐이다.**
