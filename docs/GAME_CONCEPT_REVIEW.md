> **작성일**: 2026-04-23

## 1. 게임 정체성

### 한 줄 컨셉
> **"화성 지도를 픽셀 단위로 점령하고, 경제·전투·거래로 생존·성장하는 P2E 전략 게임"**

### 코어 루프
```
입금(USDT) → 영토 점령(PP) → 자원 채굴(PP 회수) → 아이템·코스메틱 구매(GP) →
전투·꾸미기·거래 → 시즌 랭킹 경쟁 → USDT 출금
```

### 주요 재화
| 재화 | 역할 | 획득 경로 | 사용처 |
|---|---|---|---|
| **USDT** | 실제 가치 | 입금 / 출금 | 입출금만 가능 |
| **PP** (Pixel Points) | 게임 기축통화 | 입금 보너스(+10%) / 채굴 / 미션 | 영토 구매, 탈취, 일부 아이템 |
| **GP** (Game Points) | 소프트 커런시 | PP→GP 교환 / 미션 / 미니게임 | 강화, 마켓, 칸티나 베팅 |

### 플랫폼
- **Web** (모바일 최적화 + 데스크톱 풀 기능)
- Ethers.js 기반 지갑 연결 (Base / BNB / ETH 3체인)
- 서버: Node.js + Postgres + Railway 배포

## 2. 코어 플레이 시스템

### 2.1 영토 시스템 (Core)
- **화성 지도**를 3D 글로브로 렌더링 (픽셀 그리드)
- 유저가 **구역(claim)**을 선택 → PP 지불 → 이미지+링크 업로드
- 영토는 시간 경과에 따라 **자원(PP)** 생성 → 수확(harvest)
- **하이잭(탈취)**: 다른 유저의 영토를 1.2배 비용으로 빼앗기 (피해자 100% 환불 + 10% 보너스)
- **섹터 시스템**: 화성을 24개 섹터로 분할, 지역별 거버넌스

### 2.2 전투 시스템
- **하이잭**: 적 픽셀 공격 (기본 전투)
- **평화협정 / 전시**: 거버넌스로 on/off (전시에는 20% 할인)
- **방어 아이템**: 기본/고급 쉴드로 하이잭 차단
- **공격 아이템**: EMP, 오비탈 스트라이크, 바이러스, 디코이

### 2.3 미니게임 (Cantina)
- 크래시, 마인즈, 코인플립, 다이스, 하이로 — 5종
- GP 베팅 → 배당
- 일일 미션 "Cantina Night" 연동

### 2.4 탐험 (POI)
- 화성 지도에 랜덤 POI 생성 → 유저가 발견
- 보상: GP / PP / 아이템 / 코스메틱 (드롭 확률 설정)

### 2.5 로켓
- 주기적으로 로켓 발사 이벤트 → 루팅 드롭

### 2.6 날씨
- 화성 기상 이벤트 (모래폭풍 등)
- 채굴률 / 이동 / 방어에 버프·디버프
- 일일 미션 "Storm Chaser" 연동

## 4. 경제·커뮤니티

### 4.1 길드
- 길드 생성 → 멤버 모집 → 길드 채팅
- **길드 전쟁**: 길드 간 미니게임
- 길드 금고 (GP 전용)
- 연구 효과 (버프)

### 4.2 거버넌스
- 섹터별 **Governor / Commander** 선출
- 세금 징수 → 분배
- 전쟁 / 평화 / 할인 이벤트 결정

### 4.3 아이템 상점
- **방어**: Basic/Advanced Shield
- **공격**: EMP, Orbital Strike, Virus, Decoy
- **유틸**: Teleporter, Scanner, etc.
- **부스터**: XP/PP/채굴 배율
- **코스메틱**: border, glow, terrain 슬롯 (3종×N디자인)

### 4.4 코스메틱 강화 시스템 (NEW, 방금 완료) ⭐
- 인벤토리 스택(quantity) → 개별 인스턴스로 **물질화** (materialize)
- **+0 → +10** 강화 (레벨당 GP 비용 1.8x 증가)
- 성공률: 95% → 7% (레벨별 감소)
- 실패 페널티:
  - 50% 유지 / 40% 하락 / 10% 파괴
- **비주얼 차등화**:
  - +1~+3: 흰색 글로우
  - +4~+6: 금색
  - +7~+9: 보라
  - +10: 빨강 + 펄스 애니메이션
- 배지: `+7`, `+10 MAX` 등

### 4.5 마켓플레이스 (NEW, 방금 완료) ⭐
- **3종 거래 대상**: 강화된 코스메틱 / 일반 아이템 인스턴스 / 영토(claim)
- **고정가 판매** (Phase 3 완성):
  - 등록비: 2 GP
  - 판매 수수료: 5%
  - 기본 기간: 7일
  - 최대 활성 리스팅: 20개/유저
- **에스크로**:
  - 아이템: `wallet='escrow'`로 이동
  - 클레임: `marketplace_locked=true` → 탈취 차단
- **UI**: BROWSE(필터/정렬/검색) / SELL(판매) / MY LISTINGS
- **가격 히스토리**: 아이템별 거래 가격 추적
- **자동 만료**: 5분마다 만료 리스팅 정리
- **어드민 관리**: 통계, 활성 리스팅, 강제 취소, 설정

## 10. 요약

**PIXEL WAR / OCCUPY MARS**는:
- **픽셀 영토 점령** + **P2E 경제** + **시즌 경쟁** 을 결합한
- 블록체인 전략 게임 플랫폼.

방금 추가된 **마켓플레이스 + 강화 시스템**으로
- 유저 간 거래 경제 활성화
- 장기 목표(+10 도전) 제공
- GP 싱크 강화 → 인플레이션 억제
