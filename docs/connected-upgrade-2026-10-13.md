# Occupy Mars 통합 업그레이드 — 2026-10-13

기존 사실적 아트와 그림형 하단 메뉴를 유지하며, 미배포 수정분과 마지막 결함을 통합했다. 이 문서는 구현·검증 범위를 기록하며 실제 이용자 재미·매출 검증을 대신하지 않는다.

## 완료한 변경

- 생산 보관량 4→16회(8시간). 30분 생산 속도 유지. 마이그레이션351은 이전4회 상한으로 정산·시각을 전진한 후 상한을 확장하여 과거 초과 생산을 소급 지급하지 않는다.
- 물류 통제 시 화물100→200개, 시간10→9분. 광산 직접 인출 우회를 막고 운송 후 정비·제작에 사용한다. 철 분말/함체 판재 모두 운송 가능하며 개인·길드 재고와 권한을 분리한다.
- 32종 함선의 수리 재료를 제작 예산·수리 비율에 맞춰 제한했다. 비철광석 레시피는 재료 단위 합계, 레시피 없는 조립 함선은 최대 제작 예산238단위를 기준으로 한다. GP 공식은 유지했다. 고급 조립 함선의 높은 GP 부담은 이용자 경제 실험 대상이다.
- 품질 보너스를 강화 횟수로 오인하던 가격 계산 수정. 재조립은 품질·성공 강화·HP·보호막을 유지하고 장착 파츠가 있는 함선 해체는 거절한다. 과거 상태 기록 없는 해체는 추측 복원하지 않는다.
- 캠페인 선택 반복 보상·동시 지급 오류 수정. 숨김1장에는 같은 계정의 3진영1장 완료가 필요하다. 기존 진행 권한은 유지하고 실패한 CV 장에서 다음 장이 열린다는 잘못된 표시를 제거했다.
- 새 카지노 베팅과 효과 미구현 주문 사용을 중단했다. 기존 정산·현황 조회는 보존한다. 길드/초기 작전/기록 알림을 실제 행동 화면으로 연결했다.
- 작전실 함대 상세 렌더 오류와320픽셀 편성 목록이15픽셀로 눌리던 배치를 수정했다. 통신/메뉴 겹침, 코스메틱 아트 잘림을 실제 브라우저에서 재확인했다.
- 7개 언어 작전실·카드·재조립 문구를 보완하고, 번역 검사가 누락·영문 대체·태그/플레이스홀더 오류에 실패하도록 강화했다.
