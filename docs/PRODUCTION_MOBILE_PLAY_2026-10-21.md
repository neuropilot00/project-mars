## 발견해 수정한 결함

1. `.mbg.open` 가입/점령 창 위에 통신 버튼이 올라왔다. 기존 모달 차단 조건으로 통신·지도 보조 조작을 함께 숨기고 닫으면 복귀하도록 CSS만 수정.
2. 모바일 가입 입력11px·약관/기억 옵션6.5px. 기존 색상/레이아웃 안에서 입력16px, 옵션/오류12px, 옵션 높이44px로 보강. 좁고 짧은 화면은 기존 모달 내부 스크롤을 유지.
3. `/api/factions/stats`500. 운영 로그의 PostgreSQL 임시파일 ENOSPC와 사용자×함선 JOIN 증폭 확인. 사용자/생존 함선을 각각 선집계. 통계 계약·파벌·플레이어 데이터는 보존. 별도 실제 PG/HTTP 회귀1통과. 볼륨 자체를 확장하거나 다른 공간 원인을 복구한 조치는 아니다.
4. `/api/user/:wallet/base`에 `gp`가 없어 실제85GP여도 기지0GP 표시. 기존 SELECT에 gp_balance, 응답에 숫자형 gp만 추가. 3회귀로 잔액/기존 응답 보존.
5. 내 영토 상세에서 PP 추정치를 실제 PP지급처럼 표시하고 수확 관리 동선이 끊겼다. PP환산 추정치·실제GP지급을 명시하고 본인 영토에 기존 BASE 영토탭으로 가는44px 관리 버튼 추가. 소유권 재검사,7언어,9회귀.
6. 무료/새 땅 점령에도 기존 소유자 환급·탈취 수수료 문구가 노출됐다. 실제 중복 점령 상태일 때만 해당 기존 문구 표시. 가격/회계/유료 계약 변경 없음.
7. 재료 부족은 색만 흐려지고 버튼은 클릭 가능했으며 GP부족을 사전에 확인하지 않았다. 실제 재료자격+보유GP로 버튼을 비활성화하고 이유를 표시, 확인창/POST 전 진입 방어. 서버 최종 검증은 유지.
8. 보유 아이템의 작은 필터/본문. 모바일 필터44px, 기존 아트와 색상은 유지하며 제목14px/본문·사용버튼12px.
