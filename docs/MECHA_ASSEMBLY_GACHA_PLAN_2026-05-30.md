# 합체 슈퍼유닛 (볼트론형) 한정 가챠 기획서
> 작성: 2026-05-30 · 대상: OCCUPY MARS · 상태: 기획 초안 (구현 전 검토용)
> 핵심 컨셉: **5개 파츠를 모으면 1기로 합체하는 슈퍼로봇**을 **퍼펙트(컴플리트) 가챠**로 공급. 성능은 **중상위(타이탄급 한 끗)**, 최상위 압도 금지. 톤은 **Pilgrim Arms 실험병기**로 격리.

---

## 0. 한 줄 정의
> "Pilgrim Arms가 봉인했던 5기 1조의 합체병기 — 파츠를 모으면 합체해 함대전에 투입하는, **수집형 한정 가챠 슈퍼유닛**."

---

## 1. 설계 원칙 (먼저 박는 가드레일)

성패는 "강함을 어디에 두느냐"가 아니라 **"4종 레드라인을 동시에 켜지 않는 것"**.

| 레드라인 속성 | 이 기획의 처리 |
|---|---|
| 한정(limited) | ✅ 시즌 한정 라인 유지 (수집 욕구 핵심) |
| 가챠 전용(gacha-only) | ⚠️ **완화** — 파츠는 가챠 외 비과금 루트로도 일부 확정 획득 |
| **상위 성능(top-tier)** | ❌ **제거** — 합체체는 **중상위**(타이탄 동급±, 압도 X) |
| 손실 가능(loss) | ⚠️ **완화** — 파츠/합체체 **비매각·계정귀속·격침해도 영구손실 없음**(재합체 쿨다운/수리만) |

→ **상위성능을 빼고, 가챠전용·손실을 완화.** "한정"만 순수 유지 → P2W 낙인·파워크리프 동시 회피.

### 1-1. 성능 포지션 (확정)
- 합체체 = **중상위**. 단일 타이탄과 **호각 또는 살짝 위**. "2~3척 몫" 절대 금지.
- 차별점은 **스탯 우위가 아니라 유틸/연출**: 광역기, 진형 무시 돌파, 1회성 합체 필살기 등 **"숫자"가 아닌 "역할"로 특별**.
- 무한강화(`ship_stat_upgrade_log`)와 충돌 방지: 합체체는 **무한강화 제외 또는 별도 낮은 캡** → 풀강 정규 타이탄이 따라잡을 여지 = "과금=무적" 차단.

## 2. 수집 구조 — "퍼펙트 가챠"의 안전한 변형

### 2-1. 컴플리트 가챠(コンプガチャ) 법적 주의 ⚠️
순수 컴플리트 가챠(랜덤 세트 완성해야만 희귀 보상)는 **일본 2012년 위법 판정**. 본 게임 JA 로컬라이징 보유 → **순수 컴플리트 가챠는 피하고 "박스 가챠 + 천장 + 직접 획득"**으로 동일한 수집 쾌감을 살리되 법적/평판 리스크 제거.

### 2-2. 채택 모델: **박스 가챠 + 확정 천장 + 분해 교환**
- **5종 파츠**: 머리(코어)·좌완·우완·좌각·우각 (또는 5색 기체). 각 파츠 = 독립 인벤토리 아이템.
- 합체체 = **5파츠 모두 보유 시 결정론적으로 합체** → "랜덤으로 합체체가 튀어나오는" 구조 아님 = 컴플리트 가챠 회피.
- **가챠 1회 = 파츠 1개**(랜덤). 단:
  - **하드 천장(pity)**: N회(예 80) 누적 시 미보유 파츠 중 하나 확정 → 이론상 100% 완성 보장.
  - **중복 완화**: 중복 파츠는 **조각(shard)**로 자동 분해 → 조각 M개로 **원하는 파츠 확정 교환**(소프트 천장).
- **비과금 루트**: 시즌 패스/캠페인/이벤트로 **파츠 1~2개 확정 지급** → 무과금도 한 시즌 1기 완성을 "어렵지만 가능"으로.

### 2-3. 한정성 & 복각
- 시즌 한정 라인. 종료 후 신규 획득 불가(보유분 영구 유지) → FOMO + 수집 가치.
- **복각(rerun)**: 일정 시즌 후 복각으로 신규/복귀 구제(영구 박탈은 이탈 유발).

## 3. 합체 규칙 (메커니즘)

| 항목 | 규칙 |
|---|---|
| 합체 조건 | 5파츠 전부 보유 + GP·재료 소모(경제 sink) |
| 합체체 | `ship_types` 신규 1종(`pilgrim_voltaris` 등). size_class = 신규 `assembled`(표기는 타이탄 위, 성능은 중상위) |
| 분리 | 합체 후 쿨다운 동안 분리 불가. 분리 시 파츠 환원(손실 없음) |
| 격침 | 영구손실 ❌ — "대파" 상태 → **수리(GP+재료)** 후 재합체. 긴장감은 수리비·쿨다운으로 |
| 함대 편입 | 함대당 1기, 기함 가능. 계정당 시즌 보유 상한 |
| 거래 | **비매각·계정귀속**(파츠·합체체) → 현금 2차시장 P2W 차단 |
| 전용기 | 1회성 합체 필살기(전술랩 빔포/미사일 차지 시스템 재활용). 광역·고연출·쿨다운 |

## 4. 밸런스 격리 (22척 작업 자기무효화 방지)
- 합체체 **무한강화 제외/별도 캡** → 풀강 타이탄이 따라잡을 여지.
- 상성(`getShipMatchupMult`, migration 208)에 합체체 행/열 추가 — **명확한 카운터**(ewar/tackle 다수에 묶이면 무력화). "무적" 아님.
- 함대전 매칭/리그에 합체체 보유 여부를 **전력 산정 반영** → 비보유자 일방학살 방지.

---

## 5. 톤 — Pilgrim Arms 실험병기 격리
- 정규 3파벌(MCC/FSP/CV)은 **사실적 SF 함대** 유지. 메카 ❌.
- 합체체 = **Pilgrim Arms**(캠페인 후반 숨겨진 4세력)의 **봉인된 실험병기** 서사 → 이질적 메카가 오히려 자연스러움.
- 비주얼: 사실적 결 유지한 **세미리얼 메카**(기존 캠페인 아트 톤 정합). 풀애니풍 지양.
- 캠페인 연결: Pilgrim Arms 등장 챕터(MCC/FSP CH9 전후)에서 파츠 첫 조우 → 가챠 라인 오픈 명분.

---

## 6. 경제 연결 (GP sink)
- 합체 시 GP + 재료(Core/Mid 광물) 소모 = 건조·강화 다음가는 신규 sink.
- 격침 후 재합체 수리비 = 지속 sink.
- 파츠 조각 교환 = 광물/GP 소비.
- 순환: 합체체 운용 = 고비용 → 채굴·마켓·강화 수요 동반 상승.

## 8. 가챠 수치 (초안 — 전부 `settings` 기반, 하드코딩 금지)
- 파츠 풀: 5종 균등(각 20%) 가정.
- 하드 천장: 누적 80회마다 미보유 파츠 확정. → **반드시 조각 교환(소프트 천장) 병행**으로 체감 단축.
- 조각: 중복 1회 = 조각 10, 파츠 교환 = 조각 50(중복 5회) → 운 나빠도 결국 완성 보장.
- 비과금: 시즌당 확정 파츠 1~2개.
- **EV/지갑보호**: 평균 완성 비용 사전 시뮬레이션, 천장 표기 의무화.

1. **P0 — 서사/아트 선행**: Pilgrim Arms 실험병기 컨셉아트 + 합체체/5파츠 PNG (톤 검증 먼저).

5. **P4 — 격리·매칭·복각**: 무한강화 제외, 전력 매칭, 시즌/복각 운영.
