# 합체 슈퍼유닛 (볼트론형) 한정 가챠 기획서
> 작성: 2026-05-30 · 대상: OCCUPY MARS · 상태: 기획 초안 (구현 전 검토용)
> 핵심 컨셉: **5개 파츠를 모으면 1기로 합체하는 슈퍼로봇**을 **퍼펙트(컴플리트) 가챠**로 공급. 성능은 **중상위(타이탄급 한 끗)**, 최상위 압도 금지. 톤은 **Pilgrim Arms 실험병기**로 격리.

## 0-1. 팀 스트레스 테스트 반영 (v2 · 2026-05-30 · 디자이너·경제학자·악마의대변인·비판검토)

> **결론: "할 만하지만, 현재 형태로는 출시 불가." 3대 레드라인을 먼저 닫지 않으면 매출보다 리스크가 크다.**

**🔴 출시 전 필수 레드라인 (악마의 대변인 — 만장일치 강조)**
1. **PvP 성능 격리** — 합체체 성능을 랭크/리그/함대전 매칭에 투입 금지. PvP에선 **코스메틱(스킨/필살기 비주얼)만** 노출, 성능은 PvE·캠페인 한정. "전력 매칭 반영"은 격차를 *측정*할 뿐 *제거*하지 못함(측정된 격차 = 비보유자에겐 "돈 안 써서 진다"는 증거).
2. **법무 사전검토** — PP↔GP 입금→가챠 경로는 **한국 확률공개법(2024.3, 형사처벌)·EU FOMO/미성년자·가상자산 규제** 동시 사정권. 확률 공시 + 표기-실제 드롭의 감사 가능한 일치(불변 로그)가 없으면 형사 리스크.
3. **계정/지갑 OTC 거래 차단** — 비매각·계정귀속이어도 **지갑 통째 거래**로 무력화됨("완성 계정 OTC 판매"). 지갑 양도 탐지 + 약관 금지 + 적발 시 회수 조항을 출시와 동시에. 없으면 비매각 방어 전체가 선언적 허구.

**🟠 구조적 모순 (비판 검토 — 가장 큰 사각)**
- **횡적 파워크리프**: "무한강화 제외"는 *합체체 vs 정규함선* 종적 크리프만 막음. 가챠 BM 본질은 "시즌마다 신규 합체체 라인" → **합체체 N vs N+1 횡적 크리프는 구조적으로 불가피**(호각=신규 살 동기 0=매출 0, 살짝 위=누적 크리프). → §4에 정량 정책 신설(아래).
- **"중상위"는 측정 불가 정성표현** → 정량 success metric으로 재정의(아래).
- **전술랩 필살기 "재활용"은 과소평가** — 차지 시스템은 *시뮬 계층 명령*. 실제 서버 전투 반영은 **신규 API/WS command 구축**(CLAUDE.md v5.54). P3을 "재활용"이 아니라 "신규 서버 전투명령"으로 재라벨.

**🟢 채택할 디자이너 재설계 (재미 훅)**
- 합체체 = "또 하나의 강한 함선"이 아니라 **전장 페이즈 전환 트리거** — 합체 발동 = 1회, 아군 전체 광역버프 + 적 진형 강제붕괴. 가치는 *자기 스탯*이 아니라 *함대 전체용 페이즈 스킬*.
- **분리/합체 트레이드오프**(핵심): 분리=5파츠가 5척 소형 호위함(넓게 탱킹/스크린), 합체=1척 슈퍼유닛(필살기 보유, 단일 집중사격에 취약). → 매 전투 "넓게 깔까 vs 한 점에 몰까"의 *의미 있는 결정* 생성, ewar/tackle 카운터도 자연 작동.
- 성장축: 스탯 무한강화 대신 **합체 필살기 시즌 숙련**(쿨다운↓/범위↑/추가차지), 시즌 임무·운용 횟수로만 해금.

**🔵 검토된 대안 (BM 재분기 — 보류 옵션으로 기록)**
- (A) 신규 함급 대신 **타이탄 장착 "Pilgrim Arms 오버드라이브 모듈 5파츠"** → 상성표·전투엔진·전력산정 무수정으로 밸런싱 지옥 회피.
- (B) 가챠 대신 **시즌패스/캠페인 결정론 100% 지급 + 과금은 속도(시간단축)만 판매** → P2W 낙인·확률공개법·약탈과금 리스크 통째 제거. 단 FOMO 매출은 포기.

## 1. 설계 원칙 (먼저 박는 가드레일)

성패는 "강함을 어디에 두느냐"가 아니라 **"4종 레드라인을 동시에 켜지 않는 것"**.

| 레드라인 속성 | 이 기획의 처리 |
|---|---|
| 한정(limited) | ✅ 시즌 한정 라인 유지 (수집 욕구 핵심) |
| 가챠 전용(gacha-only) | ⚠️ **완화** — 파츠는 가챠 외 비과금 루트로도 일부 확정 획득 |
| **상위 성능(top-tier)** | ❌ **제거** — 합체체는 **중상위**(타이탄 동급±, 압도 X) |
| 손실 가능(loss) | ⚠️ **완화** — 파츠/합체체 **비매각·계정귀속·격침해도 영구손실 없음**(재합체 쿨다운/수리만) |

→ **상위성능을 빼고, 가챠전용·손실을 완화.** "한정"만 순수 유지 → P2W 낙인·파워크리프 동시 회피.

### 1-1. 성능 포지션 (정량 success metric — 정성표현 폐기)
- "중상위"를 **측정 가능한 밴드로 정의**(비판 검토 반영):
  - **목표 승률 밴드**: 합체체 포함 함대 vs 동급 정규 함대 승률 **52~55%** 이내(압도=60%+ 금지, 무의미=50% 금지).
  - **픽률 상한**: 보유자 함대전 출전율 상한 설정 — 초과 시 너프 트리거.
  - **출시 게이트(P3 acceptance)**: 전술랩 시뮬 + 서버 `battleEngine` 자동 N회(≥1000) 시뮬로 승률 밴드 검증 통과해야 출시.
- 차별점은 **스탯 우위가 아니라 페이즈 스킬/연출**(§0-1 디자이너 재설계). 무한강화(`ship_stat_upgrade_log`)는 **완전 제외**(낮은 캡도 금지 — 캡까지 미는 과금압력 발생). 성장 욕구는 필살기 시즌 숙련으로 흡수.

## 2. 수집 구조 — "퍼펙트 가챠"의 안전한 변형

### 2-1. 컴플리트 가챠(コンプガチャ) 법적 주의 ⚠️
순수 컴플리트 가챠(랜덤 세트 완성해야만 희귀 보상)는 **일본 2012년 위법 판정**. 본 게임 JA 로컬라이징 보유 → **순수 컴플리트 가챠는 피하고 "박스 가챠 + 천장 + 직접 획득"**으로 동일한 수집 쾌감을 살리되 법적/평판 리스크 제거.

### 2-2. 채택 모델: **박스 가챠 + 확정 천장 + 분해 교환**
- **5종 파츠**: 머리(코어)·좌완·우완·좌각·우각 (또는 5색 기체). 각 파츠 = 독립 인벤토리 아이템.
- 합체체 = **5파츠 모두 보유 시 결정론적으로 합체** → "랜덤으로 합체체가 튀어나오는" 구조 아님 = 컴플리트 가챠 회피.
- **가챠 1회 = 파츠 1개**(랜덤). 단:
  - **하드 천장(pity)**: N회(예 80) 누적 시 미보유 파츠 중 하나 확정 → 이론상 100% 완성 보장.
  - **중복 완화**: 중복 파츠는 **조각(shard)**로 자동 분해 → 조각 M개로 **원하는 파츠 확정 교환**(소프트 천장).
- **비과금 루트**: 시즌 패스/캠페인/이벤트로 **파츠 1~2개 확정 지급** → 무과금도 한 시즌 1기 완성을 "어렵지만 가능"으로.

### 2-3. 한정성 & 복각
- 시즌 한정 라인. 종료 후 신규 획득 불가(보유분 영구 유지) → FOMO + 수집 가치.
- **복각(rerun)**: 일정 시즌 후 복각으로 신규/복귀 구제(영구 박탈은 이탈 유발).

## 4. 밸런스 격리 + 횡적 크리프 정책 (22척 작업 자기무효화 방지)
- 합체체 **무한강화 완전 제외** → 풀강 타이탄이 따라잡을 여지.
- 상성(`getShipMatchupMult`, migration 208)에 합체체 행/열 추가 — **명확한 카운터**(ewar/tackle 다수에 묶이면 무력화·분리 강제). "무적" 아님.
- **PvP 격리(레드라인 1)**: 함대전/리그/랭크 매칭에선 성능 미투입(코스메틱만). 보유 여부 전력산정은 *측정*일 뿐 격차 제거 못함.
- **횡적 크리프 정책(신설 — 비판 검토 최대 사각 대응)**: 신규 시즌 합체체 라인은
  - 구 시즌 라인 대비 **승률 ±3% 밴드 내** 유지(스탯 누적 금지).
  - 신규성은 **역할/연출/필살기 패턴으로만** 차별(횡적 스탯 우위 금지).
  - 매 시즌 출시 게이트에 "신규 라인 vs 기존 전 라인" 시뮬 승률 검증 포함.
  - 이 정책이 없으면 §1 가드레일 전체가 1시즌짜리.

## 5. 톤 — Pilgrim Arms 실험병기 격리
- 정규 3파벌(MCC/FSP/CV)은 **사실적 SF 함대** 유지. 메카 ❌.
- 합체체 = **Pilgrim Arms**(캠페인 후반 숨겨진 4세력)의 **봉인된 실험병기** 서사 → 이질적 메카가 오히려 자연스러움.
- 비주얼: 사실적 결 유지한 **세미리얼 메카**(기존 캠페인 아트 톤 정합). 풀애니풍 지양.
- 캠페인 연결: Pilgrim Arms 등장 챕터(MCC/FSP CH9 전후)에서 파츠 첫 조우 → 가챠 라인 오픈 명분.

## 6. 경제 연결 (GP sink)
- 합체 시 GP + 재료(Core/Mid 광물) 소모 = 건조·강화 다음가는 신규 sink.
- 격침 후 재합체 수리비 = 지속 sink.
- 파츠 조각 교환 = 광물/GP 소비.
- 순환: 합체체 운용 = 고비용 → 채굴·마켓·강화 수요 동반 상승.

## 8. 가챠 수치 (몬테카를로 20만 시행 검증 — 전부 `settings` 기반, 하드코딩 금지)

⚠️ **핵심 발견(경제학자):** 5종×20%는 100종 풀이 아니라 **얕은 쿠폰수집가 문제**다. 천장·조각 없이도 완성 **평균 11.4뽑 / 중앙값 10 / P95 21 / P99 28**. 따라서:
- **80회 하드천장은 완전한 장식** — P99(28)의 3배라 사실상 발동 0%. "이론상 100% 보장" 문구만 있고 체감 보호 0. → **30회로 하향**(불운자도 30뽑 내 완성 보장이 실제로 성립).
- **소프트천장(조각)이 유일하게 작동하는 보호장치** — 켜면 평균 8.69뽑, P95 21→13. 중복=15/교환=40(≈2.67중복/파츠)로 조이면 **P95 9 / P99 10**으로 운빨 격차가 한 자릿수로 수렴(스위트스폿).
- **무과금 결정론 루트 명시** — 시즌 무료트랙 50조각(=1파츠) + 캠페인 확정 1파츠 → 시즌당 안정 2파츠, 복각 포함 **약 2.5시즌 완성**(1기/시즌은 과욕, 2~3시즌이 적정).

```
gacha_assembly_part_count                  = 5
gacha_assembly_part_weight_each            = 0.20
gacha_assembly_hard_pity_pulls             = 30      # 80→30 (실효 천장)
gacha_assembly_pity_grants_missing         = true
gacha_assembly_dup_shard_yield             = 15      # 10→15
gacha_assembly_shard_exchange_cost         = 40      # 50→40 (≈2.67중복/파츠)
gacha_assembly_freetrack_shards_per_season = 50      # 무과금 결정론 1파츠
gacha_assembly_campaign_guaranteed_parts   = 1
gacha_assembly_assemble_gp_cost            = <titan_build_gp * 1.75>   # 건조와 강화 사이
gacha_assembly_repair_gp_cost              = <titan_repair_gp * 2.5>   # 지속 sink
```

## 10-B. 프레임워크 — 새 한정 유닛 추가법 (코드 0줄, 데이터만)

합체/수집형 한정 유닛은 `assembly_units` 카탈로그 기반으로 일반화됨(로봇·함선·우주인·메크 등 `kind` 자유). **새 유닛 추가 = SQL 3종 INSERT만**:

```sql
-- 1) 합체 결과 함선 (size_class='assembled', 중상위 스탯)
INSERT INTO ship_types (code, faction_code, size_class, role, ..., is_active) VALUES ('<unit>', ...);
-- 2) 유닛 카탈로그 (유닛별 전 설정: 가격/천장/조각/시즌/max 등)
INSERT INTO assembly_units (unit_code, ship_type_code, kind, name_*, gacha_price_gp, hard_pity_pulls, season_code, ...) VALUES (...);
-- 3) 파츠 N종
INSERT INTO assembly_parts (part_code, unit_code, slot, name_*, icon_emoji) VALUES (...);
```
→ `/api/assembly/units`에 자동 노출, 조선소 ASSEMBLY 탭에 **유닛 선택자**로 자동 등장, 가챠/천장/조각/합체/해체/전투(assembled 매치업·overdrive 필살기) 전부 그대로 동작. 아트(`assets/ships/top/<ship>.png`, `assets/assembly/parts/<part>.png`)만 추가하면 이모지→이미지.

- 유닛별 천장은 `user_assembly_gacha (wallet, unit_code)` 로 독립.
- `season_code <> 'permanent'`면 UI에 '한정' 뱃지. 상시는 'permanent'.
- 전투: `size_class='assembled'`면 자동으로 카운터 매치업(저격/폭격/전자전) + overdrive 충전 대상.

## 11. 미결 5건 — 팀 권고 (디자이너 기준, 확정 제안)
- [x] **파츠 테마 → 5함급 변형**(스카우트/돌격/포격/방패/지휘). 부위(머리/팔)는 분리 시 비주얼 우스꽝, 5색은 정체성 얕음. 5함급은 "분리=5척 역할 함대"와 직결.
- [x] **함대 슬롯 → 1슬롯 차지(별도 슬롯 금지)**. 별도 슬롯=공짜 추가전력=즉시 P2W. 1슬롯이라야 "타이탄 뺄까 합체체 넣을까" 기회비용 성립.
- [x] **대파-수리 → 수리비=타이탄 건조비 30~50% + 쿨다운 6~12h, 영구손실 없음**. GP보다 *시간*을 주 게이트로(경제학자는 건조×1.75/수리×2.5 GP 제안 — §8과 병행 튜닝).
- [x] **비과금 지급 → 시즌당 확정 2개(코어 1 + 주간임무 1)**, 나머지 3개는 가챠/조각. 출발선 2/5, 5/5 공짜 지급 금지. 컴플리트가챠 회피 실효는 "코어를 비과금 확정으로" 주는 데서 나옴.
- [x] **무한강화 → 완전 제외**(낮은 캡 아님). 캡은 과금압력 유발. 성장은 필살기 시즌 숙련으로 대체.
