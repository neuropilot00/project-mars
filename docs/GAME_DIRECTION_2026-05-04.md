# OCCUPY MARS — Game Direction Lock

> Date: 2026-05-04
> Purpose: 현재까지 구현된 캠페인, 영토, 조선소, 함대전, 경제/마켓 시스템을 하나의 게임 방향성으로 묶기 위한 기준 문서.

## 1. One-Line Pitch

OCCUPY MARS는 화성의 영토를 사고 꾸미고 생산지로 키우며, 캠페인으로 세계관을 따라가고, 함선을 자산처럼 제작·강화·거래해 전쟁과 시장에서 영향력을 넓히는 화성 개척 경제 전략 게임이다.

## 2. Current Diagnosis

현재 프로젝트는 기능이 부족한 상태가 아니다. 오히려 시스템이 많이 붙어 있어 플레이어가 "오늘 무엇을 해야 재미있는가"를 한눈에 알기 어려워질 위험이 크다.

라이브/준라이브 축은 이미 충분하다.

- 화성 영토 클레임, 이미지 등록, GP/PP 경제
- 캠페인 스토리와 챕터 진행
- 조선소, 함선 제작, 확률 강화, 함선 마켓
- 함대전, 함대 지휘, 진형/기동, 택티컬랩
- 섹터, 거버넌스, 시즌 점수, 길드/수송, 마켓/옥션

따라서 다음 단계는 새 기능 추가가 아니라, 기존 기능들을 하나의 플레이 루프로 연결하는 것이다.

## 3. Core Fantasy

플레이어는 단순 방문자가 아니라 화성 개척 세력의 지휘관이다.

플레이어가 느껴야 하는 감정은 네 가지다.

- 내 땅을 가진다.
- 내 땅을 꾸미고 보여준다.
- 내 함선을 키우고 거래한다.
- 내 세력이 전쟁과 시장에서 커진다.

이 네 감정이 연결되면 OCCUPY MARS의 정체성이 생긴다.

## 4. Four Pillars

### 4.1 Campaign: 읽는 몰입

캠페인은 기능 설명 페이지가 아니라 소설처럼 게임 세계에 들어가는 입구다.

역할:

- 세계관과 세력 갈등을 전달한다.
- 플레이어에게 다음 행동의 이유를 준다.
- 복잡한 시스템을 자연스럽게 하나씩 열어준다.

중요 원칙:

- 캠페인을 처음부터 새로 갈아엎지 않는다.
- 기존 챕터, 이미지, 캐릭터, 에디터 데이터를 최대한 유지한다.
- 새로 필요한 것은 "스토리 전체 재작성"이 아니라 "목표, 보상, 잠금 해제, 시스템 연결"이다.

### 4.2 Territory: 소유와 표현

영토는 단순 픽셀이 아니라 플레이어의 부동산, 갤러리, 광고판, 생산지다.

역할:

- 플레이어가 게임 안에 흔적을 남긴다.
- 이미지 등록으로 그림판/갤러리의 재미를 만든다.
- 생산, 시즌 점수, 섹터 영향력과 연결된다.

중요 원칙:

- 내 영토와 남의 영토는 멀리서도 식별되어야 한다.
- 이미지 등록은 게임의 핵심 감성 중 하나로 계속 강화한다.
- 영토는 함선 경제와 캠페인 진행의 자원 기반이 되어야 한다.

### 4.3 Fleet: 자산 경제

함선은 일회성 전투 유닛이 아니라 자산이다.

역할:

- 제작하고 모으는 재미를 만든다.
- 강화로 장기 성장 욕구를 만든다.
- 마켓 거래로 "강화된 함선 판매" 같은 유저 경제를 만든다.
- 함대전에서 실제 전투력과 손익으로 연결된다.

중요 원칙:

- 함종/진영별 상성이 명확해야 한다.
- 같은 가격이면 한 함선만 사는 구조를 피한다.
- 강화는 확률, 재료, GP 소모가 명확히 보여야 한다.
- 판매중인 함선은 UI에서 즉시 알아볼 수 있어야 한다.

### 4.4 War: 경제 이벤트

전쟁은 별도 미니게임이 아니라 경제와 영토의 충돌이다.

역할:

- 함선 제작/강화의 이유가 된다.
- 섹터/시즌/거버넌스의 긴장감을 만든다.
- 시장 가격과 자원 수요를 흔든다.

중요 원칙:

- 함대전은 박력 있어야 하지만, 근접 난전처럼 보이면 안 된다.
- 세로 탑뷰 함대전은 현재 방향이 맞다.
- 자동 줌, 장거리 교전, 함선 방향, 빔포/미사일, 무전 콜아웃이 핵심이다.
- 직접 조종형 에이스 모드는 본서버 핵심으로 바로 넣지 않고 별도 실험 레이어로 둔다.

## 5. Main Game Loop

기본 루프는 다음처럼 잡는다.

1. 캠페인이 목표를 준다.
2. 플레이어가 화성에서 영토를 확보하거나 탐사한다.
3. 영토와 활동에서 GP/PP/자원을 얻는다.
4. 자원으로 함선을 제작하거나 강화한다.
5. 함대전, 섹터 경쟁, 마켓 거래에 참여한다.
6. 보상과 영향력으로 다음 캠페인/영토/함대 목표가 열린다.

이 루프가 고정되면 메뉴가 많아도 플레이어는 길을 잃지 않는다.

## 6. Campaign Scope Control

캠페인을 새로 만들면 일이 커지는가?

답: 전면 재작성으로 가면 일이 매우 커진다. 지금 선택해야 할 방향은 전면 재작성 금지다.

해야 할 일:

- 기존 챕터 구조 유지
- 기존 배경/캐릭터/대사 최대 재사용
- 챕터별 목표만 실제 게임 행동과 연결
- 보상과 잠금 해제 추가
- 진행률/완료 조건을 서버 기준으로 정리

하지 말아야 할 일:

- 기존 캠페인 전체 폐기
- 모든 대사 재작성
- 모든 이미지 재생성
- 챕터 수를 먼저 늘리기
- 캠페인만 따로 노는 별도 게임으로 만들기

가장 현실적인 방식은 "캠페인 리마스터"다.

예시:

| 챕터 | 기존 역할 | 붙일 실제 목표 |
|---|---|---|
| 프롤로그 | 세계관 진입 | 지갑/기본 UI/첫 목표 안내 |
| CH1 | 산소 쟁탈 | 특정 영토 확인, 자원 회수, 첫 작전 진행 |
| CH2 | 이동/수송 갈등 | 수송/섹터/길드 시스템 맛보기 |
| CH3 | 정치/이사회 | 거버넌스/투표/세력 평판 연결 |
| CH4+ | 분쟁 확대 | 함선 제작, 함대 지휘, 전투 결과 연결 |

이러면 새 캠페인을 만드는 것이 아니라 기존 캠페인을 게임 루프의 안내선으로 바꾸는 작업이 된다.

## 7. Priority Roadmap

### P0. Direction Lock

- 이 문서를 기준으로 앞으로의 기능 판단을 한다.
- 새 기능을 붙일 때 네 기둥 중 어디에 속하는지 먼저 확인한다.
- 캠페인, 영토, 함대, 경제 중 어디에도 연결되지 않는 기능은 보류한다.

### P1. Campaign as Main Quest

- 캠페인 챕터를 실제 게임 행동과 연결한다.
- 완료 조건은 서버가 판정한다.
- 완료된 챕터는 접어서 보여준다.
- 진행 중 챕터는 "다음 할 일"이 명확해야 한다.

### P2. Fleet Battle Feel

- 본서버 택티컬랩을 세로 탑뷰 함대전 기준으로 완성한다.
- 함선은 화면 밖으로 나가지 않아야 한다.
- 함선은 공격 대상을 바라봐야 한다.
- 소규모전은 더 가까이, 대규모전은 더 멀리 시작한다.
- 빔포/미사일/무전/배경/사운드로 박력을 만든다.

### P3. Ship Economy

- 함선 제작 재료/보유량/부족량을 명확히 표시한다.
- 강화는 확률, 재료, GP 소모가 항상 보인다.
- 강화된 함선은 마켓에서 가치 있게 보여야 한다.
- 판매중 함선은 모든 관련 UI에서 명확히 구분한다.

### P4. Territory Utility

- 영토는 이미지 등록만이 아니라 생산/섹터/시즌/캠페인 조건과 연결한다.
- 내 영토/남의 영토 식별성을 계속 개선한다.
- 좋은 영토를 가지는 이유를 경제적으로 강화한다.

## 8. UX Direction

### Main Screen

메인 화면은 화성이 주인공이어야 한다. 캠페인 버튼은 중요하지만 화성을 가리면 안 된다.

우선순위:

- 화성 보기
- 현재 시즌/알림
- 내 다음 목표
- 캠페인 진입
- 영토/조선소/마켓/베이스 이동

### Campaign UI

캠페인은 길고 무거운 목록보다 "현재 진행할 챕터"가 먼저 보여야 한다.

원칙:

- 완료 챕터는 접힘
- 진행 가능 챕터는 크게
- 잠긴 챕터는 필요할 때만 펼침
- 결과는 짧고 명확하게

### Shipyard UI

조선소는 보는 재미가 있어야 한다.

원칙:

- 세로 함선 이미지를 크게 보여준다.
- 제작 가능/불가능을 재료 보유량으로 즉시 이해하게 한다.
- 데스크탑은 4열, 모바일은 1열 중심.
- 함선 역할과 상성을 카드에서 바로 알 수 있어야 한다.

### Fleet Command UI

함대 지휘는 함선이 위를 보는 세로 전장 기준이어야 한다.

원칙:

- 진형/기동 변경 시 모달이 닫히면 안 된다.
- 선택한 함선은 명확히 표시된다.
- 기함 지정은 에러 없이 즉시 반영되어야 한다.
- 가로 배치 감각을 버리고 세로 전장 대형으로 통일한다.

## 9. Stop List

당분간 멈춰야 할 것:

- 캠페인 전체 신규 작성
- 3D 직접 조종 전투를 본게임 핵심으로 즉시 편입
- 메인 메뉴/베이스 안에 새 버튼 계속 추가
- 경제와 연결되지 않는 단발성 미니 기능 추가
- UI는 만들었지만 실제 서버 판정이 없는 기능을 핵심 루프로 홍보

## 10. Success Criteria

이 방향성이 맞게 적용되었는지는 아래로 판단한다.

- 신규 유저가 10분 안에 첫 영토/첫 캠페인/첫 함선 목표를 이해한다.
- 캠페인을 진행하면 자연스럽게 영토, 조선소, 함대전, 마켓을 경험한다.
- 함선을 제작하고 강화하는 이유가 전투와 시장에서 드러난다.
- 영토를 가진 유저가 "내 것"이라는 감각을 느낀다.
- 함대전은 작은 전투도 크게 보이고, 큰 전투는 장거리 전쟁처럼 보인다.
- 새 기능이 생길 때마다 기존 루프가 더 강해진다.

## 11. Final Direction

OCCUPY MARS는 기능 수로 승부하는 게임이 아니다.

승부처는 이것이다.

- 캠페인으로 몰입시킨다.
- 영토로 소유하게 한다.
- 함선으로 욕심나게 한다.
- 전쟁과 시장으로 부딪히게 한다.

이 네 가지가 끊기지 않으면 게임의 방향성은 선명하다.
