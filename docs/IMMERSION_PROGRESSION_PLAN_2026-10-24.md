# Occupy Mars — 몰입·성장·작전일지 실행 기획

기준: v7.500 / de3c104, 2026-10-24. 대상: 운영 웹 게임, 320·390px 모바일 브라우저.

## 판정과 제품 목표

현재는 전투·영토·생산·운송·수리·제작의 실체가 있으나, 기능의 수가 플레이 동기를 대신하고 있다. EVE의 생산·보급·함대 역할 분담과 Lineage의 명확한 성장 목표·사냥 후 재정비에서 필요한 원리를 취한다. 두 게임과 동등한 몰입, 경제 규모, 사회적 밀도를 구현·입증했다고 표현하지 않는다.

플레이어의 질문은 네 가지다: 지금 무엇을 하는가, 왜 필요한가, 무엇이 바뀌는가, 다음에는 무엇을 하는가. 첫 세션에는 작전일지가 이 네 질문에 답하고, 숙련 후에는 생산선 유지·함대 성장·선택형 이야기·길드 협력이 자율 목표가 된다.

## 플레이 흐름과 콘텐츠 역할

1. **착륙 방어**: 진영 선택 → 무료 시작 함대 → 실제 NPC 전투. 진형·집중 사격을 이해하고 생존 함대를 확보한다.
2. **광산 확보**: 작전 함대로 개인 훈련 광산 공략. 전투 승리가 생산 자산으로 이어진다.
3. **화물 호위**: 저장된 생산량 수령 → 정상 운송 → 서버 시각에 따른 도착 확인. 광산 재고가 정비 창고로 이동한다.
4. **전력 복구**: 실제 손상과 정비 견적 확인 → 수리 또는 완전 정비 상태 점검. 생존·손실·재출격 비용을 이해한다.
5. **전선 개방**: 방어 편성 저장 → 생산선 유지. 이후 개인/길드 전선·선택형 이야기·함대 성장으로 확장한다.

각 작전의 기존 보상은 정비 창고 철 분말 5개를 계정당 한 번 지급하는 서버 규칙을 유지한다. GP나 개인 인벤토리 광물 지급으로 표시하지 않는다. 완료와 보상 수령은 별도 상태다. 잠긴 작전은 이전 작전 보상 수령 조건을 설명한다.

| 활동군 | 목적·진입점 | 조건·한계 |
|---|---|---|
| 시작 작전 | 작전일지의 현재 목표, 전체 5단계 | 필수 순서, 서버 검증 |
| 이야기 | 기존 진영 캠페인/평판/보상함 | 선택 콘텐츠, 기존 챕터 잠금·실제 행동 조건 유지 |
| 반복 활동 | 기록·보상, 일일·주간·업적·시즌 | 완료/수령은 해당 서버 화면에서 확인 |
| 생산·탐사 | 내 영토 수확, 전선 생산·운송, 자원 출항 | 수확 대기·함대 점유·비용은 기존 실제 규칙 |
| 함대·산업 | 함대 편성, 조선소, 인벤토리, 제작, 시장 | 보유·필요 재료, GP, 성공률/실패 소모 확인 |
| 공동 전선 | 길드·영토 경쟁·목표형 전투 | 가입·함대 조건·손실 위험 확인, 자동 공격 없음 |

## 구현 범위

- 기존 core-navigation.js/CSS와 기지 화면을 확장한다. 새 진행도 DB·별도 완료 플래그·새 프레임워크는 만들지 않는다.
- 현재 목표를 서버 상태에서 선택한다. 완료 보상 미수령을 우선 노출하고, 진행 중에는 전선의 실제 다음 행동으로 연결한다.
- 5개 작전을 단일 일지에서 조회한다. 현재 단계를 강조하고 세부 설명은 선택해 펼친다. 나머지 단계의 상태와 선행 조건도 빠르게 확인한다.
- 전체 활동 길잡이와 재료 사용처를 기존 목적지로 연결한다. 버튼은 목적지만 열며 결제·공격·보상 지급을 자동 실행하지 않는다.
- 새 동적 버튼은 data-action 계열 위임 이벤트를 사용한다. 오류·미로그인·전체 완료·계정 전환/늦은 응답은 별도 검증한다.
- 원본 아트·캠페인·경제·운영 설정·사용자 데이터·1000MB DB 설정·TOTP 비활성을 보존한다.

## 검수 기준

- 운영 QA 계정으로 정상 UI의 광산 확보→생산 인수→운송 도착→정비→방어 연결을 실제 진행한다. 대기 시간은 조작하지 않는다.
- 새 일지에서 현재 목표/완료/잠금/보상/목적/다음 연결이 일치한다.
- 모든 활동 길잡이 버튼이 해당 기존 화면을 열고 공통 헤더로 일지에 복귀한다. 제작은 실제 가능 조건과 비용을 그대로 표시한다.
- 320·390px에서 현재 목표·전체 여정·길잡이·인벤토리의 가독성, 44px 조작 크기, 가로 넘침, 통신 겹침을 화면과 치수로 확인한다.
- 오프라인/요청 실패는 진행도 0으로 표시하지 않고 오류와 재시도를 제공한다. 로그아웃/다른 계정의 늦은 응답을 혼합하지 않는다.
- 의미 있는 격리 회귀와 문법/인라인/공백 검증을 통과한 정확한 커밋을 main에 반영한다. 실제 배포 ID, 공개 소스 해시, health/ready, 운영 화면으로 재검수한다.

## 이번 출시 이후 검증할 가설

완성된 기능 수와 몰입감은 다르다. 외부 플레이어의 첫 목표 발견, 5작전 이탈 지점, 재방문 때 목표 회상, 자발적 생산/함대 선택을 관찰해야 한다. 실제 휴대폰·다수 사용자·D1/D7 유지율·장기 경제·길드전 밀도는 이번 브라우저 검수만으로 통과시키지 않는다. 강제 대기/출석 보상/유료 요소 추가를 몰입 개선으로 간주하지 않는다.

## 실제 신규 계정 후속 동선 보강 — v7.507

5작전의 실제 전투·생산·자연 운송·철 분말10 정비·방어 저장·보상 수령을 완료했다. 보상 조회 전GP10.519에서 기록·자격 있는 업적 보상과 출석8GP를 확인한 뒤68.519가 됐다. 완료 일지에서 기록·보상을 우선하고 GP·개인 재료를 확인해 장비를 준비한다. NPC 연습전 자체의 GP/광물 보상은 없으며 무보상 훈련으로 명시한다. 이전 NPC 보급 보상 가정은 폐기했다. 기존 가격/확률/보상·PvP 해금은 유지한다.
