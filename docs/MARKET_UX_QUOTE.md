# 판매 등록 전 비용 확인

로컬 소스 개선이다. 이 거래 변경은 게임 설정, 가격, 수수료, NPC 공급량, 로그인, 입출금 정책을 변경하지 않는다.

- 고정가 아이템·영토·자원 등록은 입력 뒤 서버 견적을 확인하고 다시 승인해야 등록한다. 기존 구매 견적 API와 경매·함선 전용 시장은 그대로 유지한다.
- `POST /api/marketplace/listing-quote`는 기존 JWT 인증을 사용하고 읽기만 한다. 기존 등록 API와 등록비 계산을, 기존 구매 견적/구매 정산과 판매세 계산을 공유한다.
- 즉시 차감되는 등록비는 GP, 판매 성공 시 수입/판매세/관세는 판매 통화로 표시한다. PP와 GP를 환산하거나 합산하지 않는다. GP의 등록비 차감 후 금액은 제작원가를 제외한 현금흐름 추정이다.
- 등록 매물 수에 따른 등록비 증가와 직업·영토 할인 후 판매세를 표시한다. 할인 조회 실패는 추정이라고 밝힌다. 구매자 면제 여부를 모르므로 관세는 현재 일반 관세를 상한으로 하는 범위다. 관세 조회가 실패하면 하한을 제시하지 않는다. 미래 판매 시점의 설정 변경은 보장하지 않는다.
- 60초 견적은 비용을 예약하지 않는다. 신규 클라이언트가 보내는 `expectedListingFeeGp`, `listingQuoteExpiresAt`를 등록 직전에 확인하여 만료·등록비 변경을 차감 전에 거절한다. 기존 클라이언트가 두 필드를 생략하는 경우 기존 계약을 유지한다.
- 등록비가 0이어도 같은 판매자의 등록은 사용자 행 잠금으로 직렬화한다. 잠금을 얻은 뒤 매물 수·등록비·견적 만료를 검사하고 차감 직전 만료를 다시 검사하여 대기 중 생긴 수수료 문턱 변경이나 만료를 놓치지 않는다.
- 지연된 견적은 요청 순서·계정·기존 모달 문맥이 달라졌으면 폐기하여 다른 확인창을 덮지 않는다. 비용 확인창에 자산 ID 또는 자원 코드·수량을 표시한다.
- 비용 확인 중임을 알리고 견적 요청은 8초 후 만료시킨다. 만료 후 응답은 표시하지 않으며 등록을 자동 요청하지 않는다. 사용자가 다시 견적을 확인하도록 안내한다.
- 미판매 만료·취소에도 성공한 등록의 GP 등록비는 환불되지 않음을 설명한다. 견적 실패는 등록하지 않는다. 등록 요청 뒤 네트워크 오류 등 결과 미확정이면 내 매물/잔액 확인 후 재시도하도록 안내하며 자동 재전송하지 않는다.
- 자원 가격 입력은 서버의 기존 계약에 맞게 **묶음 총가격**으로 명명했다. 수량으로 가격을 곱하지 않는다. 견적에 개당 가격도 표시한다.
- 현재 공개 NPC 자원 매물 수와 같은 통화의 최저 단가를 표시하며, 인간 플레이어 수요와 구분한다. 마켓 카드는 `users.is_ai`를 전달받아 `[NPC]`로 표시한다. 공급 설정이나 가격은 변경하지 않는다.
- GP 판매가 등록비를 회수하지 못하는 경우 경고하지만 기존에 유효했던 거래를 막지는 않는다.

## 검증

`node --require ./server/tests/isolation-guard.cjs --test tests/market-service.test.js tests/market-routes.test.js tests/market-ui.test.js`

30개 native Node 테스트가 source text를 VM에 로드하고 DB·JWT·라우터·브라우저를 fixtures로 대체한다. 실제 의존성 모듈, `.env`, DB, 네트워크, 앱 부팅을 사용하지 않는다. 동적 등록비/할인 계산과 실제 차감 일치, 기존 구매 견적의 판매세 유지, GP/PP 분리, 관세 범위, NPC 공급, 동시 등록 잠금 대기 중 문턱 변경·만료 전 차감 방지, JWT 신뢰경계, 기존 등록 계약, UI 취소·오류·지연 견적 모달 경합·견적 타임아웃을 검증한다.

별도 소스 검토에서 동시 등록 잠금과 견적 타임아웃을 보완했다. 2026-10-21 통합본은 실제 격리 PostgreSQL/HTTP로 등록·구매·정산·경합·만료 및 자원 반환 11개 흐름을 확인했다. 운영 스키마·설정, 전체 로그인 세션과 브라우저/실기기 검증은 별도다. [통합 결과와 범위](MARKET_JOURNEY_INTEGRATION_RESULT_2026-10-21.md)를 참고한다.
