# OCCUPY MARS — Release Regression Checklist

> 목적: 최근 치명/고위험 수정분이 오픈 직전 다시 깨지지 않게 하는 반자동 릴리즈 게이트
> 사용 시점: 배포 직후(L1), 오픈 전 리허설(L2), 주간 점검(L3)

---

## 0. 공통 규칙

### 테스트 증빙 규칙
- 각 항목은 `PASS / FAIL / N/A` 중 하나로 기록
- FAIL이면 반드시 아래 3개를 남긴다
  - 재현 시각
  - 스크린샷 또는 로그 위치
  - 임시 우회 가능 여부

### 테스트 계정/권한
- 일반 유저 1개
- 자산/영토 보유 유저 1개
- 관리자 계정/시크릿 1개

### 최소 환경
- 배포 대상 URL
- DB 연결 정상
- 관리자 시크릿 준비
- 브라우저 모바일 뷰 1회 포함

---

## 1. L1 — 배포 직후 10분 스모크

### 1-1. 서버/진입
- [ ] 메인 페이지 접속 가능
- [ ] 치명적인 콘솔 에러 없이 첫 화면 렌더
- [ ] 언어 토글/기본 문구가 완전히 깨지지 않음

### 1-2. 인증
- [ ] 일반 로그인 가능
- [ ] 로그인 후 새로고침해도 세션 유지
- [ ] 로그인 필요 액션에서 적절한 안내가 뜸

### 1-3. 핵심 플레이 진입
- [ ] 내 영토 보기 진입 가능
- [ ] BASE/인벤토리 탭 진입 가능
- [ ] Shipyard 진입 가능
- [ ] Campaign 모달 진입 가능

### 1-4. 관리자
- [ ] `/admin` 로그인 가능
- [ ] 후반 탭이 빈 `x-admin-secret` 문제 없이 열림
- [ ] 관리자 통계 화면 응답 정상

### 1-5. 최근 카피 회귀
- [ ] Campaign CTA가 `작전 시작 / 작전 계속 / 결과 확인`으로 보임
- [ ] 목표 액션 라벨이 추상명사 대신 행동형으로 보임
- [ ] 목표 미완료 문구가 실패가 아니라 진행 안내 톤으로 보임

---

## 2. L2 — 오픈 전 1시간 핵심 리허설

### 2-1. 캠페인 / 온보딩
- [ ] 첫 진입 온보딩이 구형 튜토리얼과 중첩 실행되지 않음
- [ ] 초반 루프가 영토 → 수확 → 함대 → 캠페인 방향으로 읽힘
- [ ] Campaign objective action 버튼이 실제 이동 동선과 맞음
- [ ] Campaign editor가 관리자 시크릿으로 챕터 목록/에셋/개별 챕터 로드 가능

### 2-2. 영토 / 수확
- [ ] 영토 선택/점령 UI 진입 가능
- [ ] 내 영토 패널이 정상 로드됨
- [ ] harvest 1회 이상 정상 처리
- [ ] 영토 관련 핵심 버튼이 모바일에서도 눌림

### 2-3. 함선 / 함대
- [ ] Shipyard 진입 가능
- [ ] buildShip 시 다중 함대 선택 경로가 깨지지 않음
- [ ] Fleet/Cmd 화면 진입 가능
- [ ] Battle hub 또는 전투 진입 경로가 깨지지 않음

### 2-4. 상점 / 인벤토리 / 마켓
- [ ] 하단 nav/사이드 FAB의 아이템 버튼이 내 인벤토리로 진입함
- [ ] inventory 데이터 로드 가능
- [ ] market 탭 진입 가능

### 2-5. 출금 / 경제 / 관리자 정확성
- [ ] `/api/config`의 `minWithdraw` 값이 기대 설정과 일치
- [ ] 최소 출금 미만 요청 시 적절히 거절됨
- [ ] `withdraw-all` 최소값 검증 정상
- [ ] on-chain liquidity 부족 시 409 에러로 안전하게 막힘
- [ ] 관리자 contract balance가 `withdraw_all` 총지급액 기준으로 과대계상되지 않음

### 2-6. 관리자 도구 회귀
- [ ] `window.ADMIN_SECRET` 기반 후반 탭이 동작
- [ ] campaign editor auth 403 회귀 없음
- [ ] 관리자 통계/핵심 조회 탭이 최소 3개 이상 정상 응답

---

## 3. L3 — 주간 회귀팩

### 3-1. 권한/보안
- [ ] 관리자 시크릿 없는 접근이 차단됨
- [ ] 테스트 스크립트/문서에 운영용 기본 비밀번호가 남아 있지 않음
- [ ] 테스트용 외부 공개 경로가 실수로 기본값이 아님

### 3-2. 경제 무결성
- [ ] 입금/출금/withdraw-all 값 정합성 샘플 점검
- [ ] 보상/차감 로직 이상치 로그 점검
- [ ] 최근 거래/정산 이벤트 이상 여부 확인

### 3-3. 캠페인/스토리
- [ ] 대표 루트 1개 이상에서 챕터 진입/결과 확인 가능
- [ ] 결과 모달/보상 표시/재확인 버튼 정상
- [ ] 스토리 본문과 가이드 카피가 의도치 않게 섞이지 않음

### 3-4. 모바일 UX
- [ ] Telegram/모바일 뷰에서 첫 10분 핵심 버튼 클릭 가능
- [ ] 하단 nav 막힘 없음
- [ ] 지나치게 긴 버튼 라벨로 레이아웃 깨짐 없음

---

## 4. FAIL 시 즉시 분류 기준

### Stop-Ship
아래 중 하나면 오픈 보류.
- 메인 진입 불가
- 로그인 불가
- 관리자 로그인/핵심 운영 탭 불가
- 출금 정합성 이상
- campaign editor/admin auth 회귀
- 테스트용 공개 경로/기본 시크릿 노출

### High
- 영토/수확/인벤토리/Shipyard 중 1개 이상 핵심 동선 단절
- 모바일에서 첫 10분 핵심 루프 진행 불가
- Campaign CTA/가이드 문구 회귀로 행동 유도 실패

### Medium
- 일부 다국어 문구/토스트/레이아웃 깨짐
- 비핵심 관리자 탭 일부 오동작
