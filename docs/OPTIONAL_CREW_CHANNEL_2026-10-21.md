# 선택형 승무원 통신 — 로컬 구현 결과

2026-10-21. 기존 타이틀 스토리의 그림·본문·연출을 보존하며, 끝까지 읽은 사용자가 선택해서 여는 승무원 통신을 추가했다. 게임 진행·재화·전투 판정·보상에는 관여하지 않는다.

## 실제 변경

- 원래 스토리 애니메이션이 끝나면 기존 `화성 진입` 버튼 아래 접힌 `승무원 통신`이 나타난다. 정적 읽기 모드에서는 본문 끝에 둔다.
- 안에는 자동항법 기록·보급 담당 보고·정비사의 진단, 서로 다른 짧은 기록 3개가 있다. 채널과 각 기록은 처음에는 모두 닫혀 있다. 기존 작품의 대사나 이미지를 사용하지 않은 자체 문구다.
- native `details/summary`, 44px 이상 선택 영역, 기존 청동/금색 스타일, 키보드 이동을 사용한다. 닫으면 채널 DOM·이벤트·피날레를 제거하고 타이틀로 포커스를 돌린다. 다시 열면 맨 위부터, 모두 접힌 상태로 시작한다.
- 짧은 화면에서 열린 기록이 위쪽으로 잘리던 flex 중앙정렬을 auto margin과 스크롤로 고쳤다. 보너스를 열지 않아도 게임 진입 버튼으로 바로 나갈 수 있다.
- en/ko/ja/zh/id/vi/th를 연결했다. SEA 사전은 `tools/sea-i18n.js`로 생성했다.

수정 위치: `assets/main-game.js`, `assets/main.css`, `assets/i18n-sea.js`, `index.html`, `sw.js`. 검증: `server/tests/lore-ui.test.js`, loopback 전용 `server/tests/story-bonus-browser.cjs`.

## 브라우저 증거

`outputs/evidence/play-loop-followup-20261021/browser-checks.json`과 화면 3장에 저장했다. 실제 로컬 Chrome, 게임 API·계정·DB 없는 소스 fixture다.

- 한국어 원래 애니메이션을 자연 종료까지 기다렸다. 첫 피날레 관측은 시작 후85.122초였으며 종료 이벤트의 정확한 발생 시각을 뜻하지 않는다. 종료 전 채널0, 종료 후 채널1·기록3·기본 열림0 확인.
- 390×560/360×400: 선택 영역44px, 가로 넘침0, 열린 기록을 스크롤해 읽기, Tab 순환, Escape 종료, 잔류 DOM/inert0, 포커스 복귀 확인.
- 정적 모드는 fixture의 명시적 `matchMedia` 어댑터로 7언어 실제 DOM/CSS를 검사했다. 긴 태국어도 마지막 문단을 버튼 위까지 스크롤할 수 있고 재진입 시 scrollTop0이다. 실제 OS 접근성 설정이나 물리 휴대전화 검증으로 간주하지 않는다.

선택형 읽을거리 구현 완료와 실제 사용자 선호도는 구분한다. 선호도 측정을 개발 완료의 선행 조건으로 두지 않는다. 운영·배포·외부 콘텐츠 생성은 실행하지 않았다.
