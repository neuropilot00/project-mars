# WRITING_PROTOCOL

> 챕터 한 편을 처음부터 끝까지 어떻게 쓰는가의 절차.
> 매번 챕터 시작 시 본 문서 절차 따름.

---

## 챕터 작성 4단계

```
0단계: 사전 준비 (15~30분)
1단계: 아웃라인 (장 구조 잡기)
2단계: 초고 작성 (장별로)
3단계: 톤 검수 (lint)
4단계: 일관성 검수 + 사전 갱신
```

---

## 0단계 — 사전 준비

### 0-1. 톤 환기

다음 3개 문서를 다시 읽음 (이미 알아도 매번 환기):
- `STYLE_GUIDE.md` — 특히 "Lint 체크리스트" 부분
- `STYLE_GUIDE.md` 끝의 "매카시 한국어 톤의 예시" 단락 3개
- 직전 완성한 챕터의 마지막 단락 (톤 연속성 확인)

### 0-2. 챕터 정보 수집

해당 챕터의:
- `CHAPTER_OUTLINES.md` 섹션 (한 줄 요약, 무대, 시점 후보, 핵심 사건)
- `PERSPECTIVES_MAP.md`에서 이 챕터의 시점 배치
- 관련 SPEC 파일 (`_spec_reference/`에서)
- `CHARACTER_SHEETS.md`에서 등장 인물 시트
- `WORLD_BIBLE.md`에서 무대의 풍경/지리 정보
- `99_dictionary/places.md`, `characters_seen.md`, `recurring_motifs.md`에서 이미 확립된 디테일

### 0-3. 사용자 확인 (필요 시)

다음 경우 사용자께 확인 받음:
- 시점 인물이 PERSPECTIVES_MAP과 다르게 가져가고 싶은 경우
- SPEC에 모호한 부분이 있는 경우 (CV Ch3 미완성 등)
- WORLD_BIBLE의 빈 자리 영역 결정 필요 (광부 학살 가해자 등)
- 새로운 주요 인물 도입 필요한 경우
- 챕터 제목 변경 필요한 경우

작은 디테일은 알아서 결정. 큰 결정만 사용자께.

## 1단계 — 아웃라인

챕터를 **3~5 장(章, section)**으로 나눔. 각 장은 한 시점, 한 장면 단위.

### 1-1. 아웃라인 템플릿

```markdown
# 챕터 N — [제목]

**주 시점**: [인물]
**무대**: [위치]
**핵심 사건**: [한 줄]
**모티브 회수**: [차 / 곡괭이 / 손 / 침묵 등]

## 1장 — [장 제목]
- 시점: [인물]
- 무대: [위치 디테일]
- 시작 풍경: [한 줄]
- 핵심 행동: [한 줄]
- 끝 잔상: [한 줄]

## 2장 — [장 제목]
...

## 3장 — [장 제목]
...
```

### 1-2. 장의 길이

- 챕터 총 30+ 페이지를 3~5 장으로 나눔
- 한 장 평균 6~10 페이지
- 짧은 장(2~3 페이지)과 긴 장(15+ 페이지) 교차 가능
- 매카시는 짧은 장과 긴 장을 자주 교차

### 1-3. 사용자 OK 받기

아웃라인 완성 후 사용자께 보고:
- "이 챕터를 이런 3장 구조로 쓰겠습니다. OK?"
- 사용자 OK 받으면 본문 작성. 수정 요청 시 아웃라인 조정.

## 2단계 — 초고 작성

### 2-1. 장 단위 작성

장별로 작성하고 장 사이에 잠깐 멈춤. 톤 흐트러짐 방지.

### 2-2. 첫 단락 의식

각 장의 첫 단락을 매카시 톤으로 시작:
- 풍경 또는 짧은 행동
- 형용사 절제
- 단문

첫 단락 작성 후 한 번 멈춤. 톤이 맞나 자체 검수. 안 맞으면 첫 단락 재작성.

### 2-3. 작성 중 매번 의식

- 인용부호 안 쓰기 — 자동 반사
- 부사 절제 — 한 챕터 3개 이하 목표
- 직접 감정 동사 안 쓰기 — 행동·풍경으로
- "그가 말하기를", "~인 것이었다" 같은 번역체 즉시 폐기
- 한 인물 이름 한 단락에 두 번 안 부르기

### 2-4. 분량 가늠

장별 분량 가늠:
- 한 페이지 ≈ 한국어 약 800~1000자 (일반 단행본 기준)
- 30 페이지 ≈ 24,000~30,000자
- 한 장 평균 6~10 페이지 ≈ 5,000~10,000자

너무 짧으면 풍경 더 깊이, 인물의 침묵 더 길게.
너무 길면 군더더기 잘라냄.

### 2-5. 분기 결정 시점 처리

분기가 되는 챕터(예: FSP Ch8 자비 부담 결정)에서는:
- 메인 라인 = 정통 결정 (자비 50K 부담 등)
- 그 결정의 무게를 풍경·침묵으로 표현
- 다른 분기는 Phase 2에서 별도 파일로 작성

본문에서 "선택지", "분기" 같은 단어 절대 안 나옴. 결정은 인물의 행동으로.

## 3단계 — 톤 검수 (Lint)

초고 완성 후 자체 검수.

### 3-1. STYLE_GUIDE Lint 체크리스트

```
□ 큰따옴표/작은따옴표 0개?
□ 부사 (정말로, 너무, 매우, 완전히, 절대로) 한 챕터에 3개 이하?
□ 직접 감정 동사 (슬펐다, 화났다, 기뻤다, 두려워했다) 0개?
□ 번역체 0개? ("그가 말하기를", "~인 것이었다", "~기 때문이었다" 등)
□ 같은 인물을 같은 단락에서 이름으로 두 번 부르는 부분 0개?
□ "마치 ~처럼", "~와 같이" 비유 한 챕터에 5개 이하?
□ 쉼표 사용 적정? (단문은 마침표로 끊음)
□ 풍경 묘사가 형용사 가득하지 않은가?
□ 인물의 시그니처 패턴 (CHARACTER_SHEETS 참조) 등장?
□ 모티브 (차, 곡괭이, 손, 침묵 중 1~2개) 회수?
□ 시점 일관성 (한 장에 한 시점)?
□ 챕터 시작이 풍경 또는 짧은 행동?
□ 챕터 끝이 짧은 문장 또는 잔상?
□ 게임 시스템 언어 (HP, 평판, 태그, sec, phase 등) 0개?
□ 정확한 시간 표기 (3월 14일, 오후 2시) 0개? 모호한 매카시 시간으로?
```

### 3-2. 문제 발견 시

- 부사 4+ → 추가로 빼기
- 직접 감정 동사 → 행동·풍경으로 재작성
- 번역체 → 한국어 자연스러운 톤으로 재작성
- 모티브 미회수 → 적절한 자리에 한두 줄 삽입

### 3-3. 한 번 더 통독

위 체크리스트 통과 후 한 번 더 처음부터 끝까지 통독. 호흡 막히는 부분, 뜻 안 통하는 부분 수정.

## 4단계 — 일관성 검수 + 사전 갱신

### 4-1. CHARACTER_SHEETS 대조

등장한 인물의 시그니처가 빠지지 않았는지:
- Mikhail이 등장했는데 차 안 따랐으면 → 이상함, 추가 또는 삭제
- Butcher가 등장했는데 곡괭이 언급 없으면 → 한 줄 추가
- Lena가 Player를 "보스"라 부르지 않았으면 → 한 줄 수정

### 4-2. WORLD_BIBLE 대조

- 무대 풍경의 디테일 (영하 100도, 핏빛 황혼 등) 정확?
- 시간 흐름 모순 없음 (광부 학살 30년 전 등)?
- 장소 이름 일관 (Erebus Crater, Hellas Central 등)?

### 4-3. 사전 갱신

챕터에서 처음 등장한 디테일을 사전에 추가:

**`99_dictionary/places.md`**:
```markdown
## Erebus Crater (CV Ch1 첫 등장)
- 화성 광야의 분화구
- 깊이 5km, 영하 100도
- CV 본거지 150명 + 함선 25척
- 외부에서 보면 빈 분화구
- 모닥불이 가운데에 있음. 영하 100도에서도 따뜻하다고 했다.
```

**`99_dictionary/characters_seen.md`**:
```markdown
## Vasco "Crow" Reyes
- CV Ch1에서 처음 등장
- 31세, 검은 머리, 시계 모양 흉터 (오른쪽 눈썹 위)
- Player와 함께 입문 시험을 받음
- "광야 코드"를 자주 인용
- CV Ch1에서 Player를 보호함 → eternal partnership
```

**`99_dictionary/recurring_motifs.md`**:
```markdown
## 차 의식
- FSP Ch1 [Mikhail 시점]: 첫 등장. 두 손으로 따라줌. 검은 차.
- FSP Ch7 [Mikhail → Amara]: 새 의장에게 차를 따름. 30년의 차.
- (FSP Ch10 Ending 1에서 회수 예정)
```

### 4-4. 다음 챕터에 영향

이 챕터에서 결정된 것이 다음 챕터에 영향. 메모:

```markdown
## Carry-forward to next chapter
- Vasco 영구 동행 (CV Ch2~10)
- Reza 처형 → Aisha 등장 시드 (CV Ch3)
- Butcher protege 결정 → Ch6 시험 partial skip
```

```
- 분량: 약 N 페이지
- 핵심 모티브: [차/곡괭이/손/침묵 중 무엇 회수]

검토해주시고 톤·내용 OK면 다음 챕터 진행하겠습니다.
```

## 분기 변형 작성 (Phase 2)

메인 라인 36 챕터 완성 후 분기 작성. 절차:

### 1. 분기 우선순위 결정

`CHAPTER_OUTLINES.md` 끝의 "분기 변형 작성 우선순위" 참조:
- 1순위: 엔딩 분기, Three Flags 보호 선택, CV terminal decisions
- 2순위: 60_stayers, 의장 후보, 처리 방식, ceremony outcomes
- 3순위: 작은 결정의 분기

### 2. 분기 파일명

```
03_fsp/ch08_main.md          (메인: 자비 부담)
03_fsp/ch08_branch_combat.md  (분기: 전투 약속)
03_fsp/ch08_branch_steal.md   (분기: MCC 절도)
03_fsp/ch08_branch_silent.md  (분기: 침묵)
```

### 3. 분기 작성 시

- 메인의 결정 시점까지는 같은 본문 (복사 가능)
- 결정 시점부터 갈라짐
- 새로 작성하는 부분은 메인과 다른 호흡, 다른 풍경
- 분기마다 다른 시점도 가능 (PERSPECTIVES_MAP 참조)

### 4. 분기 검수

- 메인과 분기 사이 모순 없는지
- 같은 인물의 시그니처 일관 유지
- 같은 풍경이지만 다른 농도

## 작업 페이스

### 일일 작업량 권장

- 한 챕터 = 0.5~3일 작업 (분량과 복잡도에 따라)
- 30+ 페이지 챕터 = 보통 1~2일
- 핵심 모티브 회수 챕터 = 더 천천히 (2~3일)
- 분기 변형 = 메인보다 빠르게 (반나절~1일)

### 페이스 관리

너무 빠르게 쓰면 톤 흐트러짐. 매카시 톤은 천천히 써야 한다.

한 세션에 한 챕터 다 쓰지 않아도 됨:
- 1세션: 0~2단계 (사전 준비 + 아웃라인 + 1~2 장 작성)
- 2세션: 나머지 장 작성
- 3세션: 검수 + 사전 갱신

## 사용자 직접 수정 시

사용자가 챕터를 직접 손볼 수 있음. 그 경우:

1. 사용자 수정 부분을 학습
2. 다음 챕터에서 그 패턴 반영
3. 만약 사용자 수정이 STYLE_GUIDE 또는 CHARACTER_SHEETS와 모순되면 → STYLE_GUIDE 또는 SHEETS를 갱신 (사용자 패턴이 정통)

---

## 절대 잊으면 안 되는 것

매카시 톤은 한 번 흔들리면 회복이 어렵다. 매 챕터 시작 전에:

1. **STYLE_GUIDE 체크리스트** 다시 읽기
2. **인용부호 없음** — 자동 반사
3. **감정 직접 표현 금지** — 행동·풍경으로
4. **시점 일관성** — 한 장에 한 인물
5. **모티브 회수** — 차/곡괭이/손/침묵 중 1~2개

이 다섯 가지는 매번 환기.
