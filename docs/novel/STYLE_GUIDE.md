# STYLE_GUIDE

> **이 문서는 본 프로젝트에서 가장 중요한 문서다.**
> 톤이 흐트러지면 다 흐트러진다.
> 챕터 작성 전에 매번 다시 읽는다.
> 챕터 작성 후 lint 패스에서 이 문서의 체크리스트로 검수한다.

---

## 핵심 선언

이 작품은 **코맥 매카시의 한국어 번역본이 아니라** 코맥 매카시의 정신을 한국어로 다시 쓴 것이다. 번역체를 쓰면 안 된다. 한국어 그 자체로 매카시가 가능하다.

매카시의 핵심은 **건조함, 형식의 절제, 침묵, 풍경의 무게**.

이 네 가지를 한국어로 구현한다.

---

## 형식 규칙 (Hard Rules)

### 1. 인용부호 없음

대사를 큰따옴표로 감싸지 않는다. 작은따옴표도 안 쓴다.

```
❌  "광야는 우리에게 어머니야," 그가 말했다.
✅  광야는 우리에게 어머니야 그가 말했다.
✅  광야는 우리에게 어머니야.
   그가 말했다.
✅  그는 말했다 광야는 우리에게 어머니야.
```

대사가 풍경에 녹아들도록. 누가 말했는지는 문맥에서 자연스럽게 드러난다.

### 2. 형용사·부사 절제

명사와 동사로 쓴다. 형용사는 꼭 필요할 때만. 부사는 거의 안 쓴다.

```
❌  매우 차가운 바람이 거세게 불었다.
✅  바람이 불었다. 차가웠다.
✅  바람이 분다.
```

`정말로`, `너무`, `매우`, `완전히`, `절대로`, `진짜로` 같은 강조 부사는 거의 추방.

### 3. 짧은 단문과 호흡 긴 종속문의 교차

매카시 문장은 두 종류다. 짧은 단문과, 쉼표로 끝없이 이어지는 호흡 긴 문장. 그 둘이 교차한다.

```
✅  그는 의자에 앉았다. 차를 따랐다. 손이 떨리지 않았다. 그가 마지막으로
    이 의자에 앉았던 것은 30년 전 광부 학살 이후 처음이었고 그때
    그는 28살이었고 의자는 누구의 것도 아니었다.
```

짧은 단문 셋 — 그리고 한 줄로 30년을 가져오는 긴 문장.

### 4. 쉼표 절제

매카시는 쉼표를 거의 안 쓴다. 단문은 그냥 마침표로 끝. 종속문에서도 쉼표 대신 `그리고`, `그러나`로 이어붙임.

```
❌  그는 의자에 앉아서, 차를 따랐고, 손이 떨리지 않았다.
✅  그는 의자에 앉았다 차를 따랐다 손이 떨리지 않았다.
✅  그는 의자에 앉아 차를 따랐고 손이 떨리지 않았다.
```

문장 안에서 두 절을 잇는 `그리고`는 매우 매카시적.

### 5. 감정의 직접 표현 금지

"슬펐다", "화났다", "기뻤다", "두려웠다" 같은 직접 감정 동사를 쓰지 않는다.

감정은 행동, 풍경, 침묵으로 보여준다.

```
❌  그녀는 슬펐다.
✅  그녀는 차를 따랐다. 다시 따랐다. 잔이 넘쳤다. 그녀는 그것을 보지 않았다.

❌  그는 화가 났다.
✅  그는 일어섰다. 의자가 뒤로 밀렸다. 그는 의자를 똑바로 세우지 않았다.

❌  그녀는 두려워했다.
✅  그녀는 손을 가방 위에 올렸다. 손이 움직이지 않았다.
```

### 6. 이름 호명 자제

같은 인물을 짧은 단락 안에서 두 번 이름으로 부르지 않는다. "그", "그녀"로 받는다.

```
❌  부처는 의자에 앉았다. 부처는 차를 따랐다. 부처는 손이 떨리지 않았다.
✅  부처는 의자에 앉았다. 차를 따랐다. 손이 떨리지 않았다.
```

### 7. 단조로운 종결어미 반복 회피

`~다`로 모든 문장이 끝나면 단조로워진다. 그러나 매카시 톤에서 `~다`는 핵심이다. 해결: **종결어미 자체를 다양화**.

```
~다 (현재)
~었다 / ~았다 (과거)
~ㄴ다 (선언, 보편 진리)
~다 (서술 종결, 가장 흔함)
```

`였다`보다 `었다` 선호 (`그것은 광야였다` → `그것은 광야였다`도 가능하지만 `광야였다` 또는 `광야였다`로 단순화).

가끔 명사로 끝내는 문장 (한 챕터 안에 1~2번):

```
✅  그는 광야를 보았다. 침묵.
✅  손이 떨리지 않았다. 30년 전과 같았다. 같은 손.
```

### 8. 번역체 추방

```
❌  ~한 것이었다 / ~인 것이다 / ~기 때문이었다
❌  그가 말하기를
❌  ~에 다름 아니었다
❌  그것은 ~을 의미하는 것이었다
```

이런 표현은 일본어 번역체나 영어 번역체. 모두 추방.

```
✅  ~었다 / ~했다 / ~인다
✅  그는 말했다
✅  ~과 같았다
✅  그것은 ~이었다
```

### 9. 한국어 주어 생략 활용

매카시는 영어로 쓰면서도 주어를 자주 반복한다 (`he`). 한국어는 주어를 생략할 수 있다. 이걸 매카시 톤에 활용한다.

```
✅  의자에 앉았다. 차를 따랐다. 손이 떨리지 않았다.
```

주어 생략으로 인물의 익명성과 행동의 무게가 강조된다. 누구의 행동인지는 문맥에서.

### 10. 시간의 모호함

매카시는 정확한 시간을 거의 안 쓴다. "그날", "한참 후", "오랜 후", "어떤 밤".

```
❌  3월 14일 오후 2시 30분 그는 의자에 앉았다.
✅  그날 오후 그는 의자에 앉았다.
✅  한참 후 그는 의자에 앉았다.
```

게임 spec에는 정확한 시간이 있지만 (sec 1500, phase 2 등) **소설에는 가져오지 않는다.**

## 풍경 묘사

### 풍경은 인물의 내면이다

매카시에서 풍경은 장식이 아니다. 풍경이 인물이다. 광야가 인물이고 추위가 인물이다.

```
✅  광야는 영하 100도였다. 그것은 광야의 일이었고 사람의 일이 아니었다.
   사람은 거기에 있었지만 거기에 속하지 않았다.
```

### 풍경 어휘

**주로 쓰는**:
- 광야, 분지, 분화구, 협곡, 능선, 평원
- 추위, 바람, 모래, 먼지, 어둠, 별
- 손, 눈, 입, 침묵, 곡괭이, 의자, 차

**자제하는**:
- 형용사 가득한 풍경 (`아름다운 황혼`, `장엄한 산`)
- 비유 과다 (`마치 ~처럼`은 매우 절제)
- 음악적 표현

### 색상 절제

매카시에서 색상은 드물게, 그러나 정확히 등장한다.

- 화성 하늘: 핏빛, 황혼, 검음
- 광야: 흙색, 회색, 어두움
- 차: 검음
- 외투: 검은색, 회색

색을 쓸 때는 한 단어로 정확히. `짙은 핏빛이 도는 황금색 황혼` 같은 건 ❌.

## 인물 묘사

### 외양은 손과 눈에 집중

매카시는 인물의 외양을 길게 묘사하지 않는다. 손, 눈, 자세, 옷의 색깔. 그것으로 충분.

```
✅  그는 의수였다. 광산용 구식. 그가 직접 만들었다.
✅  그녀는 손을 가방 위에 올렸다. 손이 움직이지 않았다.
```

### 표정은 행동으로

매카시는 "그는 슬픈 표정을 지었다" 같은 직접 묘사 안 한다. 행동과 침묵으로 보여준다.

```
❌  그녀는 화난 표정으로 그를 보았다.
✅  그녀는 그를 보았다. 한참 보았다. 그러고 일어섰다.
```

## 대사

### 짧다

매카시 인물은 길게 말하지 않는다. 한국어 매카시 톤에서는 한 마디씩 끊어 말함.

```
✅  광야 — 코드. 자네 — 어겼어. 운반자 — 죽었지. 영구 — 그림자야.
```

(SPEC에서 작성된 대사들이 이미 이 톤에 가깝다. 회수 가능.)

### 누가 말했는지 명시 절제

매번 "그가 말했다", "그녀가 답했다"를 붙이지 않는다. 문맥상 명확하면 생략.

```
✅  광야는 우리에게 어머니야.
   영하 100도에 어머니가 따뜻하지.
   그는 차를 따랐다.
```

세 번째 줄까지 와야 누가 말했는지 알게 되는 것 — 이게 매카시 톤.

### 인물별 어법

**Mikhail**: `자네`, `우리`, `같이`, 천천히
**Chen**: `~습니다`, 정확, 짧음
**Butcher**: 한 단어씩 끊어, `광야`, `코드`, `자네`
**Lena**: 짧고 빠름, `보스`
**Cinder**: 명확, 광부 어법
**Aisha**: 슬픔의 끊어 말함

(상세는 CHARACTER_SHEETS 참조)

## 폭력 묘사

매카시는 폭력을 직접적으로 쓴다. 그러나 감정을 안 묻힌다. 사실로 쓴다.

```
✅  곡괭이가 머리를 갈랐다. 그가 무릎을 꿇었다. 그러고 쓰러졌다.
   광야는 침묵했다.
```

폭력의 결과(피, 신체 변형)를 묘사하되 **그 폭력에 대한 도덕 평가는 절대 안 함**.

```
❌  잔혹한 폭력이 그녀를 무자비하게 덮쳤다.
✅  그녀는 쓰러졌다. 일어나지 않았다.
```

---

## 침묵의 시각화

침묵을 단순히 `침묵했다`로 쓰지 않는다. 침묵을 풍경으로 만든다.

```
✅  방 안 누구도 말하지 않았다. 차가 식어갔다.
✅  그는 답하지 않았다. 잠시 후 의자가 삐걱였다.
✅  말이 없었다. 바람만 있었다.
```

## 문단 구조

### 짧은 문단을 자주

매카시는 한 문장 문단, 두 문장 문단을 자주 쓴다.

```
✅
그는 차를 따랐다.

광야는 영하 100도였다.

그녀가 들어왔다.
```

### 긴 문단은 호흡으로

긴 문단 안에서는 쉼표 적게, 마침표 적게, `그리고`로 이어붙이는 호흡.

## 다중 시점 전환

### 장(章) 단위로 시점 바뀜

같은 챕터 안에서도 장(章, section)이 바뀌면 시점이 바뀔 수 있다. 그러나 한 장 안에서는 한 시점만.

```
1장 — 운항사 시점
(중간 빈 줄 + 구분선 또는 ###)
2장 — Player 시점
```

### 시점 전환은 명시되지 않음

새 시점 인물을 처음 등장시킬 때 그가 누구인지 즉시 말하지 않는다. 행동·외양으로 자연스럽게 드러냄.

```
✅
1장 끝.

###

손이 가방 위에 있었다. 손은 움직이지 않았다. 우주선이 흔들렸다.
그녀는 흔들림을 느끼지 않았다.

(독자는 두세 문장 후에 이게 Player 시점임을 알아챔)
```

## 시작과 끝

### 챕터 시작

매카시는 챕터를 자주 풍경으로 시작한다. 인물보다 풍경이 먼저.

```
✅  영하 백 도였다. 모래폭풍이 분지를 덮었다. 분지 깊은 곳에 분화구가 있었고
   분화구 안에 거점이 있었다.

✅  화성의 밤은 길었다. 그날 밤도 그랬다.
```

### 챕터 끝

매카시는 챕터를 자주 짧은 한 문장으로 끝낸다. 또는 풍경의 흐릿한 잔상.

```
✅  그는 떠났다.
✅  광야는 침묵했다.
✅  바람이 분다.
```

---

## 회수 모티브 (반복으로 무게 만들기)

매카시는 모티브를 반복한다. 그러나 매번 약간 다르게.

본 작품의 핵심 모티브 (WORLD_BIBLE 참조):
- 차 (검은 차, 두 손, 향)
- 광부 곡괭이
- 25도 라운지 vs 영하 100도 모닥불
- 손 (떨리는지, 움직이는지)
- 침묵
- 30년

각 모티브가 챕터 곳곳에 자연스럽게 박혀야 함. 한 챕터에 모티브 1~2개 회수 권장.

## Lint 체크리스트

챕터 완성 후 자체 검수 시 확인:

```
□ 큰따옴표/작은따옴표 0개?
□ 부사 (정말로, 너무, 매우, 완전히) 한 챕터에 3개 이하?
□ 직접 감정 동사 (슬펐다, 화났다, 기뻤다, 두려워했다) 0개?
□ "그가 말하기를", "~인 것이었다" 같은 번역체 0개?
□ 같은 인물을 같은 단락에서 이름으로 두 번 부르는 부분 0개?
□ "마치 ~처럼", "~와 같이" 비유 한 챕터에 5개 이하?
□ 쉼표 사용 적정한가? (단문은 마침표로)
□ 풍경 묘사가 형용사 가득하지 않은가?
□ 인물의 시그니처 패턴 (CHARACTER_SHEETS 참조) 등장?
□ 모티브 (차, 곡괭이, 손, 침묵 중 1~2개) 회수?
□ 시점 일관성 (한 장에 한 시점)?
□ 챕터 시작이 풍경 또는 짧은 행동?
□ 챕터 끝이 짧은 문장 또는 잔상?
```

## 절대 금지 (Hard No)

다음은 본 작품에서 절대 등장하면 안 됨:

- 큰따옴표/작은따옴표로 감싼 대사
- "정말로", "너무", "매우", "완전히", "절대로" 같은 강조 부사 (한 챕터 3개 이상)
- "슬펐다", "화났다", "기뻤다" 같은 직접 감정 동사
- "마치 ~처럼", "~와도 같은" 비유 과다 (한 챕터 5개 이상)
- 게임 시스템 언어 (HP, 평판, 태그, 분기, 선택지, GP, sec, phase 등)
- 영어 약어 직접 노출 (MCC, CV, FSP는 등장 가능하지만 "Mars Chartered Corporation"으로 풀어 쓰지 않음. 매카시처럼 외래어 그대로 둠.)
- 이모지, 특수 문자
- 마크다운 굵게/기울임 (소설 본문에는)
- 챕터 안에 ### 외 헤딩 (본문은 매카시 산문)

## 매번 시작 전 의식

챕터 작성 시작 전:

## 매카시 한국어 톤의 예시 (참고용)

다음은 매카시 톤을 한국어로 구현한 예시 단락이다. 이 톤을 기준으로 작성한다.

```
화성의 밤은 검었다. 검고 길었다.

부처는 의자에 앉았다. 의자는 그가 30년 전 만든 것이었다. 그는 차를
따랐다. 검은 차였다. 향이 강했다. 손이 떨리지 않았다. 그가 마지막으로
이 의자에 앉아 손이 떨리지 않았던 것은 학살 이후 처음이었고 그때 그는
28살이었고 의자는 누구의 것도 아니었다.

들어와.

그는 말하지 않았다. 그러나 문이 열렸다.
```

```
광야는 영하 백 도였다.

그녀는 가방을 무릎에 두었다. 손은 가방 위에. 손이 움직이지 않았다.
우주선이 흔들렸다. 그녀는 흔들림을 느끼지 않았다.

이틀째라고 운항사가 말했다. 자판기 옆에서. 잠을 안 잔다고. 그녀는
듣지 않았다. 그녀는 화면 너머의 화성을 보지도 않았다. 가방을 보고
있었다. 가방은 검은색이었다. 안에 무엇이 있는지 운항사는 알지 못했다.
운항사들은 그런 것을 묻지 않았다.
```

```
Mikhail은 차를 끓였다. 두 잔. 손님이 오면 두 잔이고 혼자라도 두 잔이다.
30년 의장직 동안 그는 차를 끓였다. 광부였을 때보다 더 자주 끓였다.
그는 광부였던 시절을 자주 생각했다. 그러나 입에 올리지 않았다.

문이 열렸다.

그는 차를 따랐다. 두 손으로.

자네구나 그가 말했다.
```

이 톤이다. 이 톤으로 36 챕터를 쓴다.
