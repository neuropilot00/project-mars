# CHAPTER_OUTLINES

> 36 챕터의 한 줄 요약. 각 챕터의 무대, 시점 후보, 핵심 사건, 분기 갈림길.
> 작성 순서를 정할 때 참조.
> 챕터 본문 작성 전 해당 챕터 섹션 + 관련 SPEC 다시 읽기.

---

## 작성 순서

```
Phase 1: 메인 라인만
  Prologue → MCC Ch1~10 → FSP Ch1~10 → CV Ch1~10 → Hidden Ch1~5

Phase 2: 주요 분기 (메인 완성 후)
  각 챕터의 핵심 분기 2~3개씩
```

총 메인 36 챕터 + 분기 변형 약 80~100. 합 120~135 챕터.

## PROLOGUE

**무대**: 화성행 화물선 카리오페호. 화성 정지궤도 진입 직전.
**시점 후보**: 운항사 베르크 (1장) → Player (2장) → 화성에서 누군가 (3장, 다른 도착자 또는 정착민)
**사건**: Player가 화성에 도착. 어느 파벌과도 합류 안 함. 외부인의 첫 발걸음.
**분기 갈림길**: 챕터 끝에서 Player가 어떤 방향으로 발을 디딜 것인가의 암시 (실제 분기는 Ch1에서)
**모티브**: 자판기 갈색 액체 (차의 변형), 가방, 손이 가방 위에 있고 움직이지 않는 것
**페이지**: 30+
**참조 SPEC**: 없음 (Prologue는 spec에 없음. 처음부터 새로 씀.)

**이 챕터의 핵심 결정**:
- Player의 성별·나이 모호하게 둘 것인가 명확히 할 것인가
- 화성 첫 광경을 어떻게 그릴 것인가 (매카시의 황혼)
- Prologue 끝에서 어디로 가는가 (4 분기 시드 어떻게)

## MCC ROUTE (10 챕터)

## 분기 변형 작성 우선순위

메인 라인 36 챕터 완성 후 분기 작성. 우선순위:

**1순위 (꼭 써야 하는 분기)**:
- FSP Ch10 4 엔딩 (Citizen / Peacemaker / Disillusioned / New Chair)
- CV Ch10 4 엔딩 (Warlord / Renegade / Mercenary / Crown)
- MCC Ch10 4 엔딩
- FSP Ch9 보호 5 선택 (각각 다른 결말)
- CV Ch3 6 terminal decisions

**2순위 (있으면 좋음)**:
- FSP Ch3 60_stayers respected vs coerced
- FSP Ch7 5 의장 후보
- CV Ch2 5 처리 방식
- CV Ch1 5 ceremony outcomes

**3순위 (시간 여유 시)**:
- 작은 결정의 분기들 (이름 없는 NPC 운명 등)
