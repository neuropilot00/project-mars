# OCCUPY MARS — Test Launcher Usage

> 대상: `start-test.sh`
> 목적: 지인 테스트/로컬 확인용 임시 런처 사용 범위 명시

---

## 1. 이 스크립트의 역할

`start-test.sh`는 **상업 운영 런처가 아니다.**

이 스크립트는 아래 용도로만 사용한다.
- 로컬 서버 빠른 기동
- 지인 대상 임시 테스트
- 개인 환경에서 수동 확인

상업 운영/공개 배포 기본 경로로 쓰면 안 된다.

---

## 2. 현재 동작

기본값:
- 로컬 서버만 실행
- 외부 공개 비활성화
- 관리자 비밀번호/시크릿 평문 출력 없음

외부 공개가 필요할 때만:
```bash
ALLOW_PUBLIC_TUNNEL=1 ./start-test.sh
```

이 경우에만 Cloudflare 임시 터널을 연다.

---

## 3. 금지

다음은 금지한다.
- 상업 운영에서 기본 실행 경로로 사용
- 운영용 관리자 시크릿을 채팅/문서/화면공유에 노출
- 테스트용 임시 URL을 장기 공개 링크처럼 재사용
- 운영 환경에서 무심코 `ALLOW_PUBLIC_TUNNEL=1`로 상시 사용

---

## 4. 권장 사용 예

### 로컬 전용
```bash
./start-test.sh
```

### 임시 외부 테스트
```bash
ALLOW_PUBLIC_TUNNEL=1 ./start-test.sh
```

사용 후:
- 테스트 종료 즉시 프로세스 종료
- 임시 URL 재사용 금지
- 필요 시 관리자 시크릿 재확인

---

## 5. 운영 경계

- 운영 배포 기준 흐름: GitHub push → Railway 자동 배포
- `start-test.sh`는 운영 표준 문서/런북을 대체하지 않는다.
- 배포/장애 대응은 `docs/OPS_MINIMUM_RUNBOOK_2026-05-15.md`와 회귀 체크리스트 기준으로 수행한다.
